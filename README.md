# Classroom Attendance Android

강의실 위치와 지정 Wi-Fi 연결을 감지해 입실을 처리하고, 한국 시간 17:50에 퇴실을 처리하는 개인용 Android 앱 프로젝트입니다.

**현재 단계: 요구사항 및 설계. 이 저장소에는 실행 가능한 Android 앱이나 APK가 아직 포함되어 있지 않습니다.**

## 목표

1. 강의실 주변 도착 시 휴대폰의 Wi-Fi 자동 연결 기능과 연동합니다.
2. 지정 Wi-Fi에 연결되면 출석 사이트의 입실 가능 상태를 감시합니다.
3. 입실 가능한 상태가 되면 입실을 처리하고 실제 기록을 확인합니다.
4. 수업일 17:50에 지정 Wi-Fi 연결과 오늘 입실 기록을 확인하고 퇴실을 처리합니다.
5. 강의실 주변에 있지만 지정 Wi-Fi에 연결되지 않았으면 알림바에 연결 필요 상태를 표시합니다.

대상 사이트: [출석 페이지](https://skplanet.atosoft.net/Worknet/Present/Present.asp)

## 확정된 사용 환경

- Android 휴대폰에서 Chrome으로 출석 페이지에 접속합니다.
- 현재 사용자는 홈 화면 바로가기로 매일 접속하고 있습니다.
- 지정 Wi-Fi에서만 출석 처리가 가능하다는 사용자 설명을 전제로 합니다.
- 사용 중 재로그인을 요구받지 않았으나, 세션이 무기한 유지된다는 사실은 검증되지 않았습니다.
- 출석 페이지의 실제 HTML, 요청 구조, 인증 방식은 아직 확인하지 못했습니다.

## 구현 방향과 확인할 제약

- Android 네이티브 앱을 기본 구현 방향으로 잡습니다.
- 일반 앱은 Android 10 이상에서 꺼진 Wi-Fi를 직접 켤 수 없습니다. 저장된 네트워크의 자동 연결 또는 지원되는 갤럭시의 모드 및 루틴을 조합합니다.
- 위치는 주변 진입을 판단하는 보조 신호입니다. 백그라운드 위치 이벤트에는 지연이 있으므로 Wi-Fi 연결도 별도 시작 신호로 사용합니다.
- 화면 잠금 상태의 자동 출석은 실제 사이트 요청과 인증 구조를 확인한 후 구현 가능 여부를 결정합니다.
- 앱 내부 WebView는 Chrome 로그인 상태를 자동 공유하지 않습니다. 필요하면 앱 안에서 최초 로그인을 진행합니다.
- 17:50 예약에는 정확한 알람 권한이 필요할 수 있습니다. 예약은 처리 시작 시각이며 서버 기록 완료 시각은 응답 지연의 영향을 받습니다.
- 위치, Wi-Fi 이름, 수업 요일 및 시간은 앱 설정으로 입력할 예정입니다. 실제 위치, 비밀번호, 쿠키는 저장소에 넣지 않습니다.

## 구현 전에 필요한 정보

- 휴대폰 모델, Android 버전, 갤럭시라면 One UI 버전
- 개인정보를 가린 입실 전 / 입실 후 / 퇴실 후 화면
- 최초 본인 인증 또는 로그인 절차
- 수업 요일, 입실 허용 시간대, 예외 휴강일

사이트의 실제 처리 요청과 성공 판정 기준은 허용된 Wi-Fi에 연결한 환경에서 확인해야 합니다. 확인 전에는 요청 URL이나 버튼 선택자를 추정해 실제 출석을 실행하지 않습니다.
