# 퇴실 미확인 상태의 강의실 이탈 알림

설정한 퇴실 시각부터 앱에 퇴실 완료 기록이 없는 상태로 강의실을 벗어나면 알림을 보냅니다. 앱에서 확인한 기록을 기준으로 하므로 Chrome에서 직접 퇴실했지만 앱이 읽지 못한 경우에도 확인 알림이 나올 수 있습니다.

- 출석 예약을 켜고 강의실 위치를 등록해야 합니다. 수업 요일과 휴강일을 따릅니다.
- 앱이 오늘 입실 기록, 강의실 주변의 위치, 등록한 Wi-Fi 연결 중 하나를 관찰해야 실제 강의실 이탈 대상으로 판단합니다. 관찰 기록에는 날짜만 저장합니다.
- 등록한 강의실 반경(기본 30m)보다 `거리 - GPS 정확도`가 커야 합니다. 정확도가 반경보다 나쁜 측정은 사용하지 않습니다.
- 2분 이내의 서로 다른 위치 두 개가 최소 10초 간격으로 이탈을 나타내야 합니다. 경계·부정확한 위치·오래된 측정이 끼면 다시 확인합니다. 같은 위치를 반복 조회해 알리지 않습니다.
- 같은 날 알림을 한 번 보내면 GPS 감시를 종료합니다. 앱을 다시 열거나 서비스가 재시작되어도 중복 알림을 보내지 않습니다. 알림이 차단되어 있으면 발송 완료로 기록하지 않습니다.
- 퇴실 완료를 앱이 확인하면 이탈 알림도 해제합니다. 입실·퇴실 완료 알림은 기존대로 유지합니다.

설정 → 퇴실 시간에서 재시도 시간을 선택합니다(1–60분). 출결 확인과 GPS 이탈 감시는 이 시간 안에서만 동작합니다. 기본값은 17:50:10부터 18:00까지이며, 퇴실 시각 이전과 재시도 종료 후에는 감시하지 않습니다. 이전에 긴 이탈 감시 기간을 저장했더라도 시간 밖에서 동작하지 않습니다. 알림 발송 후 GPS 감시는 종료하고, 남은 재시도 시간에는 출결 확인만 계속합니다. 감시 중에는 알림바에 상태가 표시됩니다.

위치 항상 허용·휴대폰 위치 기능·연결 및 확인 알림이 필요합니다. Android의 위치 갱신 상황에 따라 알림 도착이 늦어질 수 있습니다. 접근성을 이용한 잠금 해제 성공 여부와 별개로 알림을 게시합니다.
