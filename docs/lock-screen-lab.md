# v0.9.0 잠금 상태 대체 클릭 시험

설정 맨 아래 → 진단 · 제작자용 → 잠금 상태 테스트 열기로 들어갑니다. 시험 방법은 기존 화면 깨우기, Extend Unlock, 신뢰 기기·장소·신체 활동, 시스템 인증을 선택할 수 있습니다.

1. Chrome 접근성을 연결합니다. 예약 시험에는 정확한 알람도 허용합니다. 강의실 Wi-Fi·출석 시간·출석 예약·자동 클릭 설정은 대체 시험의 필수 조건이 아닙니다.
2. Extend Unlock 등 신뢰 방식은 휴대폰 설정을 마친 뒤 먼저 PIN·지문으로 한 번 인증합니다.
3. ‘지금 대체 클릭 시험’으로 클릭 연결을 먼저 확인하거나, 15·30·60초를 선택하고 ‘대체 클릭 시험 예약’을 누른 뒤 화면을 끕니다.
4. 버튼이나 알림을 직접 누르지 않고 기다립니다. 앱이 Chrome 내부 시험 페이지의 버튼을 자동 클릭하고 화면 변경을 확인합니다.
5. 앱 실행 카드와 결과 알림의 성공·실패 및 이유를 확인합니다. 직접 화면을 켰거나 인증했다면 결과 기록에 남깁니다.

성공은 해당 시험의 클릭 요청이 접수되고 같은 시험 화면에서 변경된 표시를 읽었음을 뜻합니다. 실제 출석 서버·인증·입실/퇴실 결과와는 별개이며 무조작 잠금 해제 성공 여부는 실행 당시 화면 상태와 사용자의 직접 조작 기록을 함께 확인합니다. 실패·취소·만료는 이전 성공 표시를 재사용하지 않습니다.

시험 페이지는 휴대폰의 127.0.0.1 임시 포트에만 제공하며 외부 리소스와 출결 요청은 없습니다. 시험이 끝나면 페이지 제공을 닫고, 최대 40초 후에도 닫습니다. Chrome 클릭 관찰은 최대 30초, 전체 잠금 시험은 실행 예정 시각부터 2분입니다. 실제 출석 서버 접근 한도와 클릭 보류는 변경하지 않습니다.

‘잠금 유지 · 기기 연결 진단’은 기존처럼 Wi-Fi 조건만 확인하며 클릭 시험은 수행하지 않습니다. 실제 입실/퇴실 실행 버튼은 이 시험 화면에서 제거했습니다.
