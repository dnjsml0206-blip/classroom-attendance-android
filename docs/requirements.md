# 상세 요구사항

## 사용자 요구

| ID | 요구사항 |
| --- | --- |
| R-01 | Android 휴대폰에서 실행한다. |
| R-02 | 위치에 따라 강의실 주변 도착을 판단하고 지정 Wi-Fi 자동 연결과 연동한다. |
| R-03 | 지정 Wi-Fi에 연결되면 출석 감시를 시작한다. |
| R-04 | 입실 가능한 상태이면 자동으로 입실 처리한다. |
| R-05 | 수업일 한국 시간 17:50에 자동으로 퇴실 처리한다. |
| R-06 | 강의실 주변에 있지만 지정 Wi-Fi에 연결되지 않으면 알림바에 미연결 상태를 표시한다. |

## 입실

- 설정된 수업일과 입실 허용 시간대에서 감시한다.
- 지정 Wi-Fi 연결과 사이트의 허용 상태를 모두 확인한다.
- 사이트의 오늘 입실 기록을 우선 확인한다. Chrome에서 수동 처리한 입실도 인식해야 한다.
- 입실 가능 여부를 확인할 수 있을 때만 처리한다.
- 처리 후 페이지 또는 응답의 실제 기록을 다시 확인한다.
- Wi-Fi 재연결, 앱 재시작, 재부팅이 중복 입실로 이어지지 않게 한다.
- 지정 Wi-Fi 연결은 위치 이벤트가 늦게 도착하더라도 감시 시작 신호로 사용할 수 있다. 실제 처리는 정해진 조건과 사이트 확인을 거친다.

## 퇴실

- 시간대는 Asia/Seoul로 명시한다.
- 해당 수업일의 17:50에 오늘 입실 기록, 미퇴실 상태, 지정 Wi-Fi 연결, 사이트의 퇴실 허용 상태를 확인한다.
- 버튼 처리 전후에 실제 네트워크를 확인한다. 이동통신망으로의 자동 전환을 지정 Wi-Fi 연결로 오인하지 않는다.
- 사이트에 이미 퇴실 기록이 있으면 다시 요청하지 않는다.
- 오늘 입실 기록이 없거나 지정 Wi-Fi에 연결되지 않은 경우 처리하지 않고 이유를 표시한다.
- 지연 재시도는 승인된 시간 범위와 현재 조건을 다시 확인한 뒤 수행한다.
- 휴대폰이 꺼져 있거나 강제 중지된 상태까지 17:50 실행을 보장하지 않는다.
- 재시도 종료 후에는 수동 확인 알림을 남긴다. 다음 날 전날 출석을 뒤늦게 처리하지 않는다.

## 알림

알림 예시의 시각은 설명용이다. 실제 성공 알림에는 사이트에서 확인한 결과를 사용한다.

| 상태 | 표시 내용 | 동작 |
| --- | --- | --- |
| 주변 진입, 미연결 | 강의실 Wi-Fi 미연결 · 출석 대기 중 | Wi-Fi 설정 열기 |
| Wi-Fi 식별 권한 부족 | 연결 확인 권한이 필요합니다 | 앱 권한 설정 열기 |
| 입실 대기 | 입실 가능 시간을 기다리는 중 | 상태 보기 |
| 입실 확인 완료 | 입실 완료 08:52 | 오늘 기록 보기 |
| 퇴실 확인 완료 | 퇴실 완료 17:50 | 오늘 기록 보기 |
| 인증 필요 | 로그인이 필요합니다 | 앱 내 로그인 화면 열기 |
| 결과 불명확 | 출석 처리 결과 확인이 필요합니다 | 사이트 기록 확인 |
| 자동화 중지 | 자동 출석이 일시 중지되었습니다 | 다시 시작 |

- 동일 미연결 상태에서는 알림 하나를 갱신하고 매번 소리나 진동을 반복하지 않는다.
- 지정 Wi-Fi에 연결되거나 위치 범위를 벗어나면 미연결 알림을 갱신하거나 해제한다.
- 알림 권한이 없으면 앱 화면에 기능 제한을 표시한다.
- OS가 허용하는 상태 알림을 사용한다. 사용자가 알림을 해제할 수 없는 것으로 가정하지 않는다.

## 인증과 데이터

- 사용자가 Chrome에서 재로그인 없이 이용하고 있다는 관찰과 세션 무기한 유지 보장은 구분한다.
- 앱 인증 상태와 Chrome 인증 상태는 별도로 취급한다.
- 인증 정보는 기기 안에서 보호하고 원격 저장소, 로그, 분석 서비스에 보내지 않는다.
- 로그는 상태 전이, 시각, 비밀값이 없는 오류 코드만 기록한다.
- 원본 HTML, 인증 헤더, 출석 페이지에 포함된 개인정보는 기본 로그에서 제외한다.
- 좌표와 Wi-Fi 설정은 사용자가 앱에서 입력하며, 설정 삭제와 자동화 일시 중지를 제공한다.
