# 현재 요구사항 · v0.2.1

- Android 휴대폰, 기존 Google Chrome 인증 사용
- 출결 URL: https://skplanet.atosoft.net/Worknet/Present/Present.asp
- 인증 URL: https://skplanet.atosoft.net/Worknet/Present/PAuthWay.asp
- TACADEMY_5G 기본 등록, 사용자 SSID 추가·삭제
- 기본 입실 08:30–09:30, 완료 즉시 감시 종료
- 기본 퇴실 17:50, 실패 시 Wi-Fi 연결 요청, 완료 시 감시 종료
- 퇴실 실패 자동 재시도는 기본 10분으로 제한; 설정에서 1–60분으로 변경
- 입실 시작·종료, 퇴실, 수업 요일 변경
- 강의실 기본 반경 30m
- 달력으로 휴강일 추가·삭제
- 오늘 탭: 오늘 출결 현황과 오늘 로그
- 출결 현황에서 달력 조회; 앱에서 확인하지 않은 이전 기록은 Chrome에서 조회
- 설정의 인텔리전트 Wi-Fi 메뉴 이동
- 입실·퇴실 완료 알림 항상 표시; 날짜별·입실/퇴실별 분리, 앱 열기·감시 종료 시 유지, 직접 삭제 가능
- 화면 잠금 중에는 잠금 해제 후 Chrome 확인을 요청
