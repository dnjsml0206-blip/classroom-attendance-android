# v0.2.0 실제 기기 확인

- 기존 인증된 Google Chrome에서 출결 화면이 열리는가
- Chrome 접근성, 위치 항상 허용, 정확한 알람과 알림 권한이 허용되었는가
- 입실 구간 전후에는 위치·Wi-Fi 감시가 종료되는가
- 입실 기록 확인 직후 감시가 끝나고 퇴실 예약은 유지되는가
- 퇴실 시간에 실패하면 Wi-Fi 연결 요청을 받고, 연결 후 재시도 기간 안에서 처리되는가
- 퇴실 기록 확인 후 감시 및 연결 요청이 종료되는가
- 잠금 상태에서는 완료로 기록하지 않고 잠금 해제를 요청하는가
- 실제 Chrome 버튼 및 확인창, 기록 시각이 해당 휴대폰에서 올바르게 인식되는가
- 퇴실 재시도 종료 뒤 계속 감시하지 않는가
- 휴강일은 달력에서 추가·삭제되고 해당 날짜의 예약이 건너뛰어지는가
- 오늘 화면에 출결 현황·오늘 로그가 표시되고 달력에서 확인 기록을 조회할 수 있는가
- 갤럭시 인텔리전트 Wi-Fi 버튼이 해당 One UI 버전의 메뉴로 이동하는가

로컬 자동 검증 범위는 [검증 기록](verification-v0.2.0.md)에 구분했다. 실제 수강생 계정으로 한 입실·퇴실 성공을 에뮬레이터 테스트 성공과 동일하게 취급하지 않는다.
