# 실제 기기 검증 시나리오

이 파일은 전체 검증 계획이다. v0.1.0의 단위 검사 및 에뮬레이터 실행 결과는 verification-v0.1.0.md에 기록했다. 실제 계정·강의실에 의존하는 항목은 아직 미실행이다.
실제 출석 요청은 적절한 수업 상황에서만 검증하며, 개발 단계에서는 우선 조회·모의 결과로 상태 처리를 확인한다.
