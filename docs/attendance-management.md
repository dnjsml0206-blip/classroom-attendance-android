# 출결 관리 · 기록 확인 · 조퇴

## 오늘 화면

- 입실 완료 등 상태 옆의 작은 `출결 기록 확인`은 오늘 Chrome 페이지를 한 번 열어 입실·퇴실 시각을 읽는다. 입실·퇴실 및 확인 버튼을 누르지 않는 조회 전용 실행이며 등록 Wi-Fi·접근성·접속 한도를 적용한다.
- 예정 수업 종료 시각 전 `퇴실하기`는 `지금 조퇴하시겠어요?` 확인 후에만 진행한다. 앱 확인과 Chrome의 실제 퇴실 확인창을 각각 처리한다. 조퇴 승인은 해당 수동 실행에만 적용하고 예약 자동 퇴실의 시간 제한을 완화하지 않는다.
- 실제 사이트 퇴실 시각을 확인한 뒤 완료 기록·알림·오늘 남은 감시 종료를 반영한다. 오류·미확인 결과는 완료나 조퇴 횟수로 추가하지 않는다.
- `시간표 보기`는 [월 달력·과목별 과정·원본 PDF 보기](timetable.md)로 연결된다.

## 계산

2026-10-01 제공받은 과정명세서로 기간을 2026-08-31~2027-02-26(포함)으로 보정했다. 설정의 수업 요일, 공휴일, 과정 휴강일(9/23·2/5), 추가 휴강일을 반영한다. 월~금, 추가 휴강 없음 기준 평일 130일에서 공휴일 평일 8일과 과정 휴강 2일을 제외한 120일이다. 출석 인정 최소 96일, 결석 환산 허용 24일이다. 기존 122일 추정은 원본을 받기 전 계산이었다. v0.9.16부터 허용 결석은 전체 수업일의 20%이며 지각·조퇴 ⅓일을 매회 반영한다. 내부 계산은 1/15일 정수 단위로 80% 경계의 반올림 오류를 방지한다.

- 결석 환산 = 직접 결석 일수 + (지각 횟수 + 조퇴 횟수) / 3. 소수점 이하를 버리지 않고 1회는 ⅓일, 2회는 ⅔일로 즉시 반영한다. 같은 날 지각과 조퇴가 함께 있으면 각각 1회로 센다.
- 현재 출결률 = (종료된 수업일 - 결석 환산) / 종료된 수업일. 오늘 수업은 시간표상 종료 시각 이후 포함한다. 사용자 요청(2026-10-02)에 따라 미기록 지난 수업은 출석으로 계산하되 시각은 만들지 않는다. 종료된 수업이 없으면 `—`다.
- 최종 예상 출결률 = (전체 수업일 - 현재 결석 환산) / 전체 수업일. 남은 수업에 모두 출석한다는 가정을 화면에 표시한다.
- 추가 결석 가능 일수는 허용 결석에서 현재 결석 환산을 뺀 뒤 정수 일수로 내린 값과 미래 수업일 중 작은 값이다. 추가 지각·조퇴 횟수도 같은 잔여량에 3을 곱해 내리며 미래 수업일의 2배를 넘지 않는다. 이미 기준을 초과하면 초과 일수를 표시한다.
- 달력의 직접 선택 상태가 시각의 자동 분류에 우선한다. 직접 선택은 앱 기록만 바꾸고 서버 시각이나 오늘 자동 처리 완료 여부를 바꾸지 않는다.
- 지각 기준은 자동 감시 종료 시각과 분리한다. v0.9.13부터 사용자 확인 기준인 09:11부터(경계 포함) 지각으로 분류하며 설정 시각을 변경할 수 있다. 자동 분류를 끄면 직접 선택한 지각만 집계한다. 시각만 확인되고 정상 판정이 불가능한 기록은 달력에서 판정대기로 표시한다. [확인 기록 보정](attendance-classification-2026-10-01.md).
- 조퇴는 설정한 퇴실 시각보다 이른 퇴실로 분류한다. 자동 실행의 5초 여유는 조퇴 판정에 사용하지 않는다. 기준을 변경하면 시각 기반 분류를 재계산한다.
- 과거 입실 시각만 있고 퇴실이 확인되지 않은 날은 퇴실 미확인으로 표시하며, 확인된 지각은 집계에 포함한다. 기관의 공식 인정 내역과 앱 추정이 다른 경우 달력의 상태로 보정할 수 있다.

## 휴가와 복수 선택 · v0.9.14

달력의 지각·조퇴는 각각 선택하며 같이 선택하면 2회다. 휴가는 출석 인정이며 월 1일 누적, 미래 예약·취소를 지원한다. 기본 지급은 수업월 시작일이며 출결 관리에서 변경할 수 있다. 휴가일은 자동 출결에서 제외하지만 출결률의 총수업일에는 포함한다. [상세 기준과 문의 검토](attendance-revision-2026-10-02.md).
