# 출석 예약 전등 — 로컬 검증

2026-09-15, v0.9.0 기반 미배포 수정. 기존 미커밋 Wi-Fi·앱 내부 알림 변경을 포함하며, Git 커밋·푸시·릴리스 업로드를 하지 않았습니다.

- 오늘 이미지 아래에 낮·밤 테마와 어울리는 벡터 스탠드 전등과 예약 상태 문구를 추가했습니다.
- 저장된 예약 스위치에 따라 점등/소등합니다. 예약 ON이면 감시 대기 시간에도 켜집니다. 기존 화면 갱신을 사용하고 전등 애니메이션이나 별도 감시·타이머를 추가하지 않았습니다.
- 제작자 구성 단위 검사 81개, 오늘 화면 검사 24개(전등 4개 포함) 통과. lint 오류 없음, 기존 Gradle 버전 안내 1개.
- 에뮬레이터에서 낮/밤 각각 ON/OFF 전환, 감시가 꺼진 상태의 점등, 화면 재진입 없이 소등되는 동작과 화면 배치를 확인했습니다. 화면 기록은 테스트용 날짜와 가상 출결입니다. 실제 출석 URL이나 입실·퇴실 제출을 실행하지 않았습니다.
- 첫 빌드는 JBR C2 컴파일러의 네이티브 충돌로 종료됐습니다. 로컬 빌드에 `-XX:TieredStopAtLevel=1`을 적용해 재시도 후 성공했습니다. 앱 코드나 프로젝트의 기본 JVM 설정을 우회 목적으로 바꾸지 않았습니다.
- 이전에 기록한 시스템 위치 메뉴 검사 제한은 이번 전등 변경에서 재검증하지 않았습니다.
