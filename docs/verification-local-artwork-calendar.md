# 그림 속 스탠드 예약 토글과 달력 수기 수정 — 로컬 변경

> 배포 후속: 아래 내용은 당시 로컬 검증 기록입니다. 이 변경은 이후 승인된 [v0.9.2 배포](releases/v0.9.2.md)에 포함됩니다.

2026-09-15, v0.9.1 기반. 사용자의 요청에 따라 커밋·푸시·릴리스 업로드를 하지 않는다.

## 반영

- 오늘 화면의 별도 전등 아이콘 및 그리기 클래스를 제거.
- 낮·밤 그림의 스탠드 부분만 누르면 출석 예약 ON/OFF. 배경 전체의 클릭은 제거. 스탠드의 전구와 주변 반사광을 켜거나 끈 이미지로 전환. 접근성은 스탠드 영역을 현재 상태가 있는 스위치로 제공.
- 스탠드 터치 좌표에 그림과 동일한 크롭 변환을 적용하고, 휴대폰 너비가 달라도 그림 속 위치를 유지. 별도 아이콘이나 전체 그림 감광은 사용하지 않음.
- 이미지 생성 방식과 최종 에셋 경로·프롬프트는 `stand-image-prompts.md` 참고.
- 오늘 화면에서 토글하면 오늘 화면을 유지. 기존 권한 검사와 켜짐 후 5초 실행, 대기 중 끄기 취소를 유지.
- 달력의 오늘 및 지난 날짜에서 출석·조퇴·결석과 선택적인 입실·퇴실 시간을 수기 수정. 날짜를 누르면 상세 기록과 수정 버튼으로 이동.
- 잘못된 시간 형식, 입실보다 빠른 퇴실, 입실 없는 퇴실을 저장 전에 안내. 결석 선택 시 수기 시간을 비움.
- 수기 상태·시간은 별도 저장하며 실제 Chrome 확인 기록과 자동 처리 상태를 덮어쓰지 않음. 수기 기록을 삭제하면 기존 확인 기록이 다시 표시됨.
- 수기 출결은 달력에서 별표와 출처를 표시. 사이트의 출결을 변경하는 기능이 아님.

## 검증

- 제작자 APK 빌드, 단위 검사 94개 통과. lint 오류 없음.
- Android 15 에뮬레이터: 스탠드 터치와 5초 동작을 포함한 직접 실행 검사 15개, 수기 달력 검사 27개 통과.
- 스탠드 실제 터치·조명 30개(낮/밤, 280·366·412dp 너비), 예약 동작 15개, 낮·밤 화면 26개 통과.
- 달력 27개와 단위 94개를 포함해 관련 검사 총 192개 통과.
- 실제 앱 화면에서 스탠드가 켜지면 전구 및 주변의 빛이 나타나고, 꺼지면 사라짐을 확인.
- 화면 검토에서 확인한 수정 후 이전 오류 문구 잔류를 정리하고, 편집 시 오류 안내가 해제되는 것을 재검증.
- 린트 오류 0개. 경고 8개: Gradle 버전, 레이아웃 시 객체 생성 3개, 기존 ActivationRun 참조·문자열, 보존한 원본 그림 미사용, 프로그램 전용 View 생성자.
- 설치 파일은 기존 배포와 동일한 서명임을 확인.
- 모든 출결·시간은 격리된 에뮬레이터 시험 데이터로 확인. 실제 출석 사이트 호출이나 제출 없음.
