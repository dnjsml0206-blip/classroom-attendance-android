# 설정 바로가기와 확인 표시

설정·연결·임시 테스트에서 설정 항목을 누르면 해당 화면이 열립니다. 알림 설정은 앱 내부 화면에서 계속합니다. 기본 설정 7개는 실제 값을 읽어 완료/설정 필요/연결 대기로 표시합니다.

| 항목 | 확인 기준 | 이동 화면 |
|---|---|---|
| Chrome 접근성 | 서비스 연결 여부. 설정만 켜지고 연결이 없으면 연결 대기 | 공개 접근성 화면에서 이 앱 서비스 강조 |
| 위치 항상 허용 | 정확한 위치와 백그라운드 위치 권한 모두 허용 | 앱 정보 → 권한 → 위치 |
| 휴대폰 위치 | 시스템 위치 기능 켜짐 | 위치 설정 |
| 정확한 알람 | 앱의 정확한 알람 사용 가능 여부 | 앱별 알람 및 리마인더 |
| 출결 완료 알림 | 앱 알림과 입실·퇴실 결과 채널 모두 허용 | 앱 내부 알림 설정. 휴대폰 권한·채널 차단 상태도 표시 |
| 출석 예약 | 앱 예약 켜짐 | 앱의 출석 예약 영역 |
| Chrome 자동 클릭 | 앱 자동 클릭 켜짐 | 앱의 자동 클릭 영역 |

퇴실 이탈 알림의 앱 설정과 채널 허용 여부, 현재 Wi-Fi, 배터리 최적화 제외, Extend Unlock은 기본 설정과 별도로 표시합니다. 설정 완료 개수는 사이트 인증이나 자동 출석 성공을 의미하지 않습니다. 특히 Extend Unlock은 앱에서 활성 원인을 판별할 수 없어 ‘휴대폰에서 확인’으로 표시합니다.

접근성이 연결된 경우에만, 사용자가 누른 위치·배터리·Extend Unlock 메뉴의 이동을 최대 15초 동안 도와줍니다. 시스템 설정과 권한 관리 앱만 대상으로 하며 권한 스위치·허용 선택·인증 입력은 누르지 않습니다. 해당 화면을 찾을 수 없거나 접근성이 꺼져 있으면 가장 가까운 공식 설정 화면과 다음 경로를 안내합니다. Extend Unlock은 설치된 Google 신뢰 서비스가 공개한 설정 화면이 있으면 우선 열고, 없으면 제조사 설정 경로를 사용합니다.

앱으로 복귀하면 메뉴 이동을 중지하고 상태를 새로 확인합니다. 활성 접근성 연결처럼 복귀 후 늦게 바뀌는 값도 주기적으로 갱신합니다.

Android 제약의 근거:

- [공개 Settings 액션](https://developer.android.com/reference/android/provider/Settings)
- [접근성 상세 화면은 시스템/설치자 권한 필요](https://android.googlesource.com/platform/frameworks/base/+/refs/heads/android16-release/core/res/AndroidManifest.xml)
- [갤럭시 Extend Unlock 메뉴](https://www.samsung.com/us/support/answer/ANS10001343/)

일부 Android 권한 화면은 앱에 메뉴 노드를 제공하지 않습니다. 이 경우 앱별 권한 화면까지 연 뒤 ‘위치 → 항상 허용’ 경로를 안내합니다. 휴대폰 제조사·OS 버전에 따라 마지막 메뉴 선택은 직접 해야 합니다.

## 앱 내부 알림 설정

‘앱 알림 설정’에서 연결·처리 안내를 켜고 끕니다. 설정은 즉시 저장되며, 끄면 Wi-Fi 연결 요청·퇴실 미완료·강의실 이탈·Chrome 확인·오류 안내를 중지하고 이미 떠 있는 해당 안내를 지웁니다. 입실·퇴실 완료 알림은 항상 별도로 유지하고, 감시 중 표시와 실행한 테스트 알림에는 영향을 주지 않습니다. 출석 예약과 자동 처리 설정도 유지됩니다.

Android 13 이상에서 알림 권한을 요청할 수 있으면 앱 위에 시스템 권한 요청창을 띄웁니다. 앱은 Android의 전체 알림 차단이나 알림 채널 차단을 임의로 해제하지 않으며, 차단 상태를 그대로 안내합니다. 알림 설정 바로가기는 차단된 경우에도 앱 내부에 머뭅니다.

오늘 탭 맨 아래에는 Wi-Fi 상태 카드를 표시합니다. 등록 Wi-Fi가 감지되지 않으면 느낌표·큰 글씨·주황색 배경과 테두리로 ‘와이파이 미연결’을 강조하고, 감지되면 초록색 ‘대기 중’으로 바뀝니다. Wi-Fi 이름 인식 상태이며 실제 자동 처리 가능 여부나 출결 완료를 의미하지 않습니다.

## 오늘의 출석 예약 전등

낮·밤 이미지 아래의 스탠드 전등이 저장된 출석 예약 ON/OFF 상태를 표시합니다. 예약이 켜져 있으면 대기 시간에도 따뜻한 빛이 켜지고, 예약을 끄면 소등됩니다. 옆에 ‘출석 예약 켜짐/꺼짐’을 함께 표시합니다. 낮은 브라운·골드, 밤은 블루그레이·골드로 맞췄으며, 상태가 바뀔 때만 전등을 다시 그립니다.
