# 오늘 화면에서 출석 Wi-Fi 연결

오늘 우상단 Wi-Fi 상태 표시를 누르면 등록된 네트워크로 연결을 시도한다. 하나만 등록했다면 바로 진행하고, 여러 개라면 먼저 이름을 선택한다. 등록 목록이 비어 있으면 설정으로 이동한다.

## 연결 과정

1. Chrome 접근성 서비스가 연결되어 있으면 휴대폰의 Wi-Fi 설정을 열고 지정한 SSID와 정확히 일치하는 목록 항목을 한 번 선택한다.
2. 그 네트워크임이 확인되는 상세 화면·대화창에서 ‘연결/Connect’ 버튼이 확인될 때 한 번 누른다. Wi-Fi 목록의 제목 노드와 목록 컨테이너, 상세 화면의 제목·버튼 식별자를 검증한다. 이름이 비슷하거나 후보가 여러 개여서 모호한 항목은 선택하지 않는다.
3. 최대 20초 동안 확인하며, 실제 등록 SSID가 기본 인터넷 연결로 검증돼야 성공으로 표시한다. 클릭 접수는 연결 성공이 아니다.
4. 시스템 화면이 6초 동안 계속 읽히지 않으면 `SETTINGS_UNREADABLE`로 중단하고, 열려 있는 Wi-Fi 목록에서 지정 이름을 직접 선택하도록 안내한다. 화면 미수신만으로 OS 차단이라고 단정하지 않는다.
5. 앱으로 돌아오거나 다른 화면으로 이동하면 중단한다. 출결 처리·잠금 시험 등 다른 화면 작업 중에는 시작하지 않는다.

접근성 연결이 없거나 전용 설정을 열 수 없으면 Android의 시스템 Wi-Fi 선택창으로 안내한다. Wi-Fi가 꺼져 있으면 사용자가 켜야 하며, 비밀번호·인증 입력이 필요하면 해당 화면에서 이어서 진행한다. 앱은 Wi-Fi 비밀번호를 읽거나 저장하지 않는다. 지원하지 않는 제조사 화면이나 목록 밖의 항목은 자동 조작하지 않고 직접 선택하도록 안내한다. 실제 갤럭시의 메뉴 구성에 따라 자동 선택 가능 여부는 달라질 수 있다.

## 상태 표시와 기록

- 실제 출석용 기본 인터넷 연결 확인: **대기 중**.
- Wi-Fi 연결 자체가 없음: **와이파이 미연결**.
- Wi-Fi는 감지되지만 출석용 SSID·권한·인터넷 조건이 확인되지 않음: **연결 확인 필요**.
- 정확한 위치 권한·휴대폰 위치가 필요한 경우 터치 시 해당 설정으로 안내한다. VPN이 활성화된 경우 원인을 표시한다.
- 연결 단계와 최종 결과는 진단 로그의 `WIFI_CONNECT_STEP`, `WIFI_CONNECT_FINISHED`에 고정된 사유 코드로만 기록한다. SSID·시스템 화면 본문·비밀번호는 내보내지 않는다. 오늘 출석 기록에는 추가하지 않는다.

앱이 새 Wi-Fi 스캔을 반복 요청하거나 출석 서버를 열지 않는다. 출결 예약은 기존 조건을 계속 따른다.

## Android 제약

[Android 10의 Wi-Fi 구성 제한](https://developer.android.com/about/versions/10/privacy/changes#configure-wifi)으로 일반 앱이 기존 저장 네트워크 목록을 직접 읽고 `enableNetwork` 등으로 전환하는 방식은 사용할 수 없다. 따라서 이 기능은 사용자가 요청한 휴대폰 설정 화면에서 연결을 보조한다. 접근성 미연결 시에는 [시스템 Wi-Fi 패널](https://developer.android.com/reference/android/provider/Settings.Panel#ACTION_WIFI)을 사용한다. 추가 Wi-Fi 권한이나 기기 관리자 권한은 요구하지 않는다.

## 검증 범위

- Android 15(API 35) 에뮬레이터에서 오늘 상태 표시 → Wi-Fi 설정 열기와 접근성 미연결 시 시스템 Wi-Fi 패널 열기를 확인했다.
- 실제 설정 창이 보이는데 접근성 화면 루트가 전달되지 않는 현상을 관찰했다. 따라서 이 에뮬레이터에서 자동 네트워크 선택·연결 성공을 검증했다고 주장하지 않는다. 읽기 실패 시 무작정 클릭하지 않고 직접 선택 안내로 끝난다.
- 초기 에뮬레이터 부팅에는 여러 시스템 앱의 응답 지연과 창 포커스 오류가 발생했다. 앱 ANR 덤프의 메인 스레드는 메시지 대기 상태였고, 앱·설정 재시작 후 화면 전환을 재검증했다.
- 실제 갤럭시의 SSID 자동 선택은 휴대폰에서 확인해야 한다. 앱에 진단 기록을 남겨 화면 미수신·대상 행 발견·클릭 접수·인터넷 연결 확인을 구별한다.

자동 검사: JUnit 116개, Python 로그 분석 검사 21개 통과. `lintDebug` 오류 0개·경고 7개, 제작자용 debug APK 빌드 통과. 최종 APK에서 `SETTINGS_ROOT_UNAVAILABLE` → `SETTINGS_UNREADABLE` 종료와 직접 선택 안내를 확인했다. 출결 예약·자동 클릭은 끄고 시험했으며 출석 사이트에 접속하지 않았다.
