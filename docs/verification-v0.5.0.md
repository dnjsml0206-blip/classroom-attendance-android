# v0.5.0 검증 기록

2026-09-11 · Android 15/API 35 에뮬레이터 · JDK 21 · SDK 36

## 범위

잠금 시험 로그를 비공개 GitHub 저장소에 JSON 파일로 올리고, 방식별로 비교할 수 있도록 내보내기·연결·분석 경로를 추가했습니다. 실제 개인 토큰은 APK에 넣지 않으며 사용자가 기기에서 최초 연결합니다.

## 로컬 검증

- Java 단위 테스트 46개 통과: 기존 38개 + 이벤트 증거/민감 문자열 처리 8개
- Android 업로드·내보내기·암호화 검사 14개 통과
- 기존 잠금 메뉴 검사 12개 통과
- Python 분석 검사 6개 통과
- lint: 오류 0개 / 기존 Gradle 버전 안내 경고 1개
- 앱·검증 APK 빌드, 기존 앱 위 업데이트 설치 성공
- 실제 APK에서 로그 올리기 진입·빈 기록 안내·미리보기/연결/전송 컨트롤·스크롤 확인

업로드 검사는 Android Keystore 암복호화와 삭제, 동일 파일 재시도, legacy 기록 보존, 메모와 이벤트 분리, 토큰 가림, 정확한 전송 바이트와 전용 브랜치 지정, 기존 파일 충돌·공개 저장소·경로 이탈·리다이렉트 거부를 확인했습니다. HTTP 전송은 가짜 응답을 사용했으며 실제 토큰을 에뮬레이터에 넣지 않았습니다. 검사 후 앱 기록과 업로드 상태를 원래 값으로 복구했습니다.

분석 검사는 중복 test_id의 최신 판정 반영, 검증용 데이터 제외, 수동 알림 진입과 자동 처리 구분, HTTPS 응답과 인증 성공 구분, 사용자 성공 판정만 있는 경우 미확인 유지, 취소된 시험의 성공 근거 제외를 확인했습니다.

## 실제 GitHub 저장·재조회

에뮬레이터가 내보낸 합성 JSON에 verification_fixture 표시를 붙여 호스트의 기존 GitHub 인증으로 Contents API에 전송했습니다. 같은 API 버전과 비공개 저장소/전용 브랜치를 사용했습니다.

- 저장 파일: logs/lock-tests/2026-09-11/a8b20492-8858-4476-9c6d-377f24661e3c.json
- 저장 후 API로 다시 읽은 바이트가 Android에서 내보낸 파일과 일치
- 분석 도구의 git fetch → 파일 읽기 → 방식별 표 생성 성공
- 검증용 업로드 1개를 제외하고 실제 휴대폰 시험 0회로 집계

이는 호스트를 통한 실제 GitHub 저장 확인입니다. 사용자의 휴대폰에 개인 토큰을 연결한 전체 전송 흐름은 설치 후 확인해야 합니다. 실제 Extend Unlock·PIN/지문·강의실 출결 동작을 이번 변경에서 다시 시험하지 않았습니다.
