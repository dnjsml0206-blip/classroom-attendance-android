## 반영 사항

- 첫 페이지 대기는 35초, 출결 및 확인 버튼의 수락 후 결과 대기는 각각 최대 35초로 재설정. 한 시도 전체는 최대 105초. 새로고침이나 자동 재클릭을 추가하지 않음.
- 자동 감시 종료 시 이미 수락된 클릭의 결과 관찰을 정해진 시간 안에서 마무리. 예약을 직접 끄면 자동 세션은 중단.
- 접근성이 다시 연결되면 출결 감시 시간 안에서 조건을 검사하고 실행 재시도. Android 접근성 권한을 앱이 강제로 켜지는 않음.
- 오늘 화면에 낮·밤 테마와 어울리는 입실하기 / 퇴실하기 버튼 추가. 자동 감시 시간이 지나도 직접 한 번 실행 가능.
- 직접 실행도 수업일, 지정 Wi-Fi, 오늘 날짜, 퇴실 설정 시각 + 5초, 접근성, 접속 간격·일일 한도를 확인. 이전 클릭이 있으면 기록만 조회하거나, 사용자가 실제 미처리를 확인한 뒤 한 번 재시도.
- 예약 켜기(이미 켜진 상태의 재선택 포함)는 자동 클릭을 함께 켜고, 현재 입실 범위의 미처리 입실 또는 퇴실 시각 이후 미처리 퇴실을 5초 뒤 한 번 시도한다. 수업일·완료 여부를 확인하며 기존 자동 감시와의 조기 중복 실행을 막는다. 끄기·자동 클릭 끄기·화면 소멸 시 대기를 취소한다.
- 완료된 항목은 완료 표시 후 버튼 비활성화. 사이트에서 실제 시간을 관찰했을 때만 완료 기록과 완료 알림을 남김.
- 대체 클릭 시험은 이벤트 연결 뒤 준비 상태를 표시하고, 클릭 성공 문구를 버튼 자체에도 표시하여 화면 하단 결과만 의존하지 않도록 보완.
- 이전 미배포 변경(예약 전등, Wi-Fi 강조, 앱 내부 알림 설정)을 유지.

## 바로 퇴실 시험하기

1. 같은 서명의 v0.9.1 제작자 APK를 기존 앱 위에 업데이트 설치한다.
2. 강의실 Wi-Fi가 연결되고 Chrome 접근성이 연결된 상태에서 설정 → 출석 예약 켜기를 누른다. 이미 켜져 있어도 다시 누를 수 있다.
3. 오늘 화면에 5초 뒤 퇴실 시작이 표시된다. 앱을 열어 둔다. 끄기를 누르면 대기를 취소한다.
4. 5초 후 Chrome에서 오늘의 실제 기록을 먼저 읽고, 아직 미처리이면 버튼을 한 번 누른다. 예약을 켜는 명시적 실행에서는 이전 미확인 요청도 한 번 재시도할 수 있다. 서버 저장 성공은 완료 시간 확인으로 판정한다.
5. Chrome을 그대로 두고 결과를 기다린다. 퇴실 시간이 확인되면 앱 기록과 완료 알림이 생긴다. 다시 미확인으로 끝나면 반복해서 누르지 않고 새 로그를 업로드한다.

설정 → 맨 아래 진단(제작자용)에서 로그 업로드. 대체 클릭 성공은 실제 서버의 출결 저장 성공과 별개이다. 실제 갤럭시 잠금 상태에서의 성공은 기기 재시험이 필요하다.
