# 출결 판정과 사용자 확인 기록 보정 · v0.9.13

## 확인된 문제와 근거의 한계

기존 지각 기준 기본값이 비어 있어 자동 지각 판정이 실행되지 않았다. 또한 입·퇴실 시각만 존재하면 달력의 상태를 완료로 표시하여 정상 출석처럼 보였다. 정상 출석 집계와 시각 수집 완료를 혼동한 표시를 수정했다.

GitHub 로그 브랜치에서 확인 가능한 마지막 업로드는 2026-09-22다. 따라서 9/28의 기존 퇴실 시각을 확인하거나 그 날의 조퇴 오분류 원인을 확정할 수 없다. 사용자가 9/28 조퇴와 9/30 지각을 직접 확인했고, 로그가 없으면 진술대로 반영하도록 요청했다.

## 적용

- 지각 기준은 사용자 확인에 따라 09:11부터(경계 포함)이다. 09:10:59는 정상, 09:11:00은 지각이다. 출결 관리에서 기준을 바꿀 수 있다.
- 이번 개인용 제작자 APK를 설치하고 앱을 처음 열면 2026-09-28 조퇴, 2026-09-30 지각을 수기 상태로 한 번 저장한다. 기본 지각 기준도 09:11로 맞춘다.
- 보정은 제작자 빌드에만 적용한다. 일반 빌드에는 개인 날짜 기록을 추가하지 않는다.
- 기존 시각을 보존하고 없는 시각은 만들지 않는다. 원본 시각보다 사용자 확인 상태가 우선한다. 서버 기록을 변경하거나 출결 요청을 보내지 않는다.
- 일회성 적용 표식을 저장하여 이후 사용자가 바꾼 상태·지각 기준을 재실행 시 덮어쓰지 않는다. 이후 달력 수정 시 보정 출처 표시도 지운다.
- 정상 판정은 출석, 자동 판정 근거가 부족한 완료 기록은 판정대기로 표시한다. 달력 요약에서 판정대기를 정상 출석 합계에 포함하지 않는다.
- 날짜 상세에 지각·조퇴 기준과 사용자 확인 출처를 표시한다. 지각 분류를 사용자가 끄면 출결 관리 상단에도 자동 지각이 누락된다는 안내를 표시한다.

## 오늘 탭 자료 버튼 배치

시간표 보기와 오리엔테이션 자료를 같은 너비의 좌·우 버튼으로 분리했다. 버튼 사이 10dp, 위쪽 출결률 버튼과 10dp 간격을 두고 높이를 64dp로 맞췄다. 긴 자료 이름은 최대 두 줄과 글자 크기 자동 조절을 사용한다.

## 검증

- 단위 테스트 144개 통과, Android lint 오류 0개(경고 10개).
- API 35 에뮬레이터의 출결 보정·버튼 배치 검사 16개 통과. 실제 출결 서버 요청 없음.
- 캡처에서 두 자료 버튼의 글자와 간격 확인. v0.9.13(versionCode 28), 기존 업데이트 서명 일치.
