## 휴강과 출결 계산

한국 공휴일·대체공휴일 및 원본 과정 휴강을 CourseCalendar/Prefs의 공통 제외 날짜로 반영했다. 기본 월~금 기준 출결률 분모는 기존 추정 122일에서 실제 120일로, 80% 최소 출석은 98일에서 96일로 보정된다. 사용자 추가 휴강은 그대로 합산하고 날짜 중복은 한 번만 제외한다. 원본 수업이 있는 날을 사용자가 휴강/비수업 요일로 정하면 시간표는 휴강 안내와 원래 과목·시수를 함께 표시한다. 원본 월별 시수는 고정이며 사용자 설정 후에도 '원본 기준'으로 구분한다.

## 원본 보기와 변경 범위

'원본 PDF · 안내' → '원본 PDF 보기'로 앱에 포함한 동일 파일을 연다. 두 손가락/두 번 터치로 확대하고 끌어서 이동한다. 렌더링은 사용자가 열었을 때 백그라운드에서 수행하며 닫거나 화면이 종료되면 비트맵을 해제한다. 모든 시간표 데이터와 PDF는 APK에 포함되어 서버 요청·다운로드·별도 PDF 앱이 필요 없다.

앱의 수기 출결·현재 예약 상태·기존 클릭 보류는 시간표 탐색으로 수정하지 않는다. 공휴일/과정 휴강 보정 외의 수업 변경은 이 고정 원본 데이터에 자동 반영되지 않는다.
