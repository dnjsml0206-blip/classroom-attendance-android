# v0.9.15 · 출결 완료 후 잠금 모드

사용자가 PIN·패턴·비밀번호로 다음 사용 시 한 번 해제하는 조건을 확인하고 요청한 기능이다. 단순 화면 끄기와 별도로 설정 → 출결 처리 화면에 잠금 모드 옵션을 추가하며 기본 켜짐이다. 기존 화면 끄기를 사용하지 않으면 자동 잠금도 실행하지 않는다. 출결 없는 잠금 모드 테스트 버튼도 제공한다.

## 실행

1. 기존 출결 흐름이 완료 시각을 확인한 후에만 실행한다. 기록만 조회, 실패, 취소에서는 실행하지 않는다.
2. 처리 안내 화면을 제거하고 GLOBAL_ACTION_POWER_DIALOG를 한 번 요청한다.
3. com.android.systemui 또는 android 시스템 창에서 전원 끄기와 다시 시작을 함께 확인한다. 잠금 모드/잠금/Lockdown의 정확한 한국어·영문 이름만 후보로 사용한다.
4. 메뉴를 최소 600ms 관찰한다. 후보 하위 트리를 완전히 읽어 잠금 이외의 액션이 없음을 확인하고 한 번 클릭한다. 노드 한도 초과, 여러 후보, 알 수 없는 이름은 거부한다. 좌표 클릭이나 전원·긴급 항목 선택은 하지 않는다.
5. 메뉴 탐색은 4초, 클릭 후 잠금 확인은 3초로 제한한다. 기기 인증 잠금을 확인한 뒤 기존 화면 끄기로 화면도 끈다. 잠금 모드는 적용되어도 잠금화면이 켜져 있을 수 있어 두 결과를 별도 기록한다. 잠금 모드 실패 시에도 기존 화면 끄기로 마무리한다.

화면을 읽는 동안만 짧게 로컬 검사하며 서버·Chrome 접속은 추가하지 않는다. 실행 중 다른 앱 화면 자동화와 중복 출결을 막고, 명시적 취소/서비스 종료 시 콜백을 제거한다. 이벤트 로그는 전원 메뉴 요청·잠금 클릭 접수·인증 잠금 확인을 구분한다. 단말의 실제 PIN 요구 UI까지 읽어 인증 방식 복구를 보장하는 것은 아니다.

## 예상 흐름에서 달라지는 점

아침 출석 → 잠금 모드 → 사용자가 PIN 등으로 한 번 해제 → 신뢰 조건에서 Extend Unlock 유지 → 퇴실 → 잠금 모드다. Wi-Fi 재연결 자체가 잠금 모드를 해제하지는 않는다. 신뢰 장소는 위치 기반이며 Wi-Fi 이탈과 항상 일치하지 않는다. Extend Unlock은 최대 4시간이므로 점심 복귀만으로 17:50까지 유지된다고 보장할 수 없다.

삼성/Android 버전에 따라 잠금 모드 표시를 켜야 하며 접근성에 항목이 노출되지 않을 수 있다. 설치 후 설정의 잠금 모드만 테스트로 실제 휴대폰에서 확인한다. 실패해도 출결 성공 여부를 실패로 바꾸지 않는다.
