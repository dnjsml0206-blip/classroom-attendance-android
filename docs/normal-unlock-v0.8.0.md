# v0.8.0 일반 예약의 잠금 처리

## 사용 방법

설정 → 잠금 중 처리 방식에서 원하는 방식을 선택합니다. 저장된 선택을 바로 표시하며, 앱을 다시 열어도 유지됩니다. 기존 사용자와 새 설치의 기본값은 ‘알림 후 직접 해제’입니다. 일반 예약과 임시 시험은 별도 설정이며, 시험 메뉴를 숨겨도 일반 예약 기능은 유지됩니다.

| 방식 | 일반 예약 시 동작 |
|---|---|
| 알림 후 직접 해제 | 기존처럼 잠금 해제 알림 표시. 화면을 자동으로 켜지 않음 |
| 화면 깨우기 | 앱 화면으로 화면 켜기를 요청. 이미 잠금이 없으면 Chrome 연결, 잠금이 있으면 직접 해제 안내 |
| Extend Unlock · 신뢰 상태 | 화면을 깨우고 신뢰 상태이면 Android에 Keyguard 해제 요청. 인증이 다시 필요하면 알림으로 안내 |
| 시스템 인증 요청 | 화면을 깨우고 Android의 잠금 해제를 요청. 나타난 PIN·지문 인증은 사용자가 수행 |

출석 예약 ON, Chrome 자동 클릭 ON, 접근성 연결, 등록 Wi-Fi, 해당 날짜·출석 시간, 기존 사이트 접속 한도를 확인합니다. 임시 조회 시험이나 다른 설정 탐색이 진행 중이면 겹쳐 실행하지 않습니다. Chrome 연결 직전 시간·Wi-Fi·잠금 상태를 다시 검사합니다.

## 실행 제한과 종료

- 입실·퇴실 각각 한국 날짜 기준 하루 한 번 화면 깨우기를 요청합니다. 이 횟수는 Chrome 접속 횟수와 별개이며, 화면을 켠 것만으로 서버에 접속하지 않습니다.
- 요청 전에 날짜·단계·방식·부팅 식별값·경과 시각을 저장합니다. 예약 토글·방식 변경·프로세스 재시작으로 자동 재요청하지 않습니다. 이전 날짜로 시간을 돌려도 횟수를 보충하지 않습니다.
- 8초 안에 앱 화면이 포커스를 얻지 못하면 자동 실행을 종료하고 알림을 남깁니다. Activity 생성만으로 실제 화면 표시 성공이라 판정하지 않습니다.
- 한 세션은 최대 2분입니다. 종료된 세션, 이전 부팅의 세션, 시간대가 끝났거나 예약·자동 클릭이 꺼진 경우, 다른 방식으로 변경된 경우에는 Chrome으로 연결하지 않습니다.
- 사용자는 이번 화면 깨우기를 중단할 수 있습니다. 시도 후에는 알림을 통한 직접 확인으로 이어집니다. 반복적인 전체 화면 알림이나 추가 네트워크 진단은 없습니다.
- 기존 사이트 제한은 공통 3초·하루 20회, 자동 입실/퇴실 각각 3회, 재시도 2분·5분입니다. 사이트 오류·불명확한 결과 중단과 클릭 보류도 유지합니다.

## 진단

로그는 기기 내부의 최근 7일·200건 범위를 유지하고 제작자가 직접 업로드합니다. 앱의 설정·동작 로그를 오늘 출결 목록에 표시하지 않습니다.

| 단계 | 기록 |
|---|---|
| 알람 | 예정 시각, 실제 수신 시각, 지연, 예약 권한 거절 |
| 감시 | 시작 요청, 서비스 진입, 실행 거절 원인 코드 |
| 잠금 | 요청, 화면 포커스, 인증 필요, 시스템 해제 요청·응답, 종료 이유 |
| Chrome | 주소 미확인, 날짜 불일치/판독 실패, 기록 판독 실패, 버튼 미확인, 확인창 대기, 결과 갱신 대기 |
| 클릭 | 클릭 직전 저장, 클릭 요청 접수/거절, 퇴실 확인 요청, 사이트 시각 확인 |

업로드 환경에는 출석 시간 설정, 다음 알람, 감시 상태, 일반 잠금 방식, 보류된 클릭의 날짜·단계·저장 시각을 제한적으로 추가합니다. Chrome 내용·쿠키·PIN·좌표·Wi-Fi 이름은 이 진단에 포함하지 않습니다. 이전 버전의 보류 시각은 미확인으로 표시합니다. 클릭 직전 기록은 실제 클릭 성공이나 서버 처리 성공의 증거가 아닙니다.

시험 화면의 실행 목적은 자동으로 선택하지 않습니다. ‘Chrome 열기만 시험’은 출결 버튼을 누르지 않으며, ‘실제 입실·퇴실 시험’은 해당 시간과 조건이 충족될 때만 버튼을 처리합니다. 회전 등 화면 재생성에서는 현재 선택을 보존하지만, 새 시험 화면을 열면 목적을 다시 선택합니다.

## Android 제약과 확인 범위

앱 자체 Activity에 `setShowWhenLocked`·`setTurnScreenOn`을 적용하고 `KeyguardManager.requestDismissKeyguard`로 시스템 해제를 요청합니다. Chrome의 인증 세션을 복사하거나 보안 잠금을 우회하지 않습니다. 화면 표시 요청이 받아들여져도 제조사·OS 상태에 따라 실제 표시가 제한될 수 있어 포커스 관찰과 시간 제한을 별도로 둡니다.

[Android Activity 실행 제약](https://developer.android.com/guide/components/activities/secure-bal) · [KeyguardManager 공식 API](https://developer.android.com/reference/android/app/KeyguardManager)

검증은 [v0.8.0 검증 기록](verification-v0.8.0.md)에 정리합니다. 실제 Galaxy / Android 16의 Extend Unlock과 수강생 인증은 설치 후 수업 환경에서 확인해야 합니다.
