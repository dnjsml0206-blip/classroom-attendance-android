# Wi-Fi 강조 표시 / 앱 내부 알림 설정 — 로컬 검증

2026-09-15, v0.9.0 기반 미배포 수정. Git 커밋·푸시·릴리스 업로드 없음.

## 반영 내용

- 오늘 하단: 주황색 배경·테두리, 느낌표, 큰 글씨로 와이파이 미연결을 강조. 등록 Wi-Fi가 인식되면 초록색 대기 중 카드로 갱신. 낮·밤 색상 모두 확인.
- 설정·설정 상태·테스트의 알림 바로가기는 앱 내부 알림 설정으로 연결.
- 연결·처리 안내 ON/OFF 즉시 저장. OFF 시 기존 안내를 제거하고 새 안내를 억제. 입실·퇴실 완료 알림과 감시 중 표시, 실행한 테스트의 알림은 유지.
- 실제 Android 알림 허용 상태 표시. Android 13 이상 권한 요청은 앱 위의 시스템 권한창 사용. 시스템 차단을 앱이 강제로 해제하지 않음.

## 확인 결과

- 제작자 구성 `testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest` 성공.
- Java 단위 검사 81개 통과. lint 오류 없음, 기존 Gradle 버전 안내 1개.
- Android 15 에뮬레이터 오늘 화면 검사 20개 통과. 초기에는 가상 Wi-Fi 미연결로 검사 전제가 실패했으며 AndroidWifi 연결 후 통과.
- 알림 추가 검사 14개 통과: 두 바로가기의 앱 내부 이동, 실제 안내 알림 발행·중지·기존 알림 정리, 완료 알림 별도 유지, 설정 상태 표시, 재진입 시 저장값 유지, 다시 켜기.
- SettingsChecks 전체는 위치 메뉴 검사에서 실패함. 새 알림 검사 이전으로 순서를 옮겨도 재현. 기존 v0.9.0의 검사에서는 통과했으나, 해당 검사는 위치 이동 전에 Android 알림 채널 화면을 먼저 여는 다른 순서임. 화면 복귀 대기·설정 앱 재시작만으로 해결되지 않았음. 따라서 위치 메뉴 자동 탐색의 화면 상태 의존성은 미해결이며 이번 변경의 전체 설정 회귀 검사가 통과했다고 주장하지 않음. 앱 기능 코드를 추측으로 변경하지 않았음.
- 실제 출석 URL이나 입실·퇴실 제출을 사용하지 않음. 알림은 에뮬레이터의 가상 기록(2000-01-06)으로 확인 후 정리.
- 실제 휴대폰의 시스템 알림 차단·권한 거절 흐름은 별도 실기기 확인 대상.
