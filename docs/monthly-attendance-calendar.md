# 월간 출결 달력

오늘 → 달력에서 출결 조회를 누르면 월간 출결 화면이 열립니다. 이전·다음 달 버튼으로 월을 바꾸고, ‘이번 달’로 오늘 날짜를 다시 선택할 수 있습니다. 날짜를 누르면 달력 아래에 해당 날짜와 입실·퇴실 시각을 표시합니다. 시간은 앱이 Chrome에서 확인한 기록이 있을 때만 표시합니다. 수기 상태에는 시간을 입력하지 않습니다.

| 상태 | 의미 |
|---|---|
| 출석* | 사용자가 오늘·지난 날짜를 출석으로 입력함 |
| 조퇴* | 사용자가 오늘·지난 날짜를 조퇴로 입력함 |
| 결석* | 사용자가 오늘·지난 날짜를 결석으로 입력함 |
| 완료 | 입실과 퇴실 시각이 모두 확인됨 |
| 입실 | 입실 시각만 확인됨 |
| 미확인 | 오늘 또는 지난 수업일에 앱이 확인한 기록이 없음. 결석 확정이 아님 |
| 휴강 | 현재 설정에 휴강일로 등록됨 |
| 예정 | 현재 설정에 따른 미래 수업일 |
| 비수업 | 현재 설정한 수업 요일에 포함되지 않음 |

실제 입실·퇴실 기록은 현재 요일·휴강 설정보다 우선합니다. 예를 들어 출결을 확인한 토요일을 이후 비수업 요일로 바꿔도 그날은 완료 상태로 표시합니다. 지난 수업 일정 변경 이력은 저장하지 않으므로 기록이 없는 날짜의 요일·휴강 표시는 현재 설정 기준입니다.

확인된 기록이 없는 날짜는 시각 영역을 표시하지 않습니다. 월간 요약은 출석(사이트 완료 + 직접 입력 출석)·조퇴·결석·입실만 확인·미확인 날짜 수를 보여줍니다. 직접 입력한 날짜는 선택한 분류에 한 번만 집계합니다. 달력을 보는 동안 앱의 출결 기록이 갱신되면 표시도 갱신됩니다.

오늘 화면의 ‘오늘 출석 기록’은 오늘 확인된 입실·퇴실 시각만 표시합니다. 설정 변경, Wi-Fi 등록, 감시 시작·종료와 같은 앱 동작 로그를 읽거나 표시하지 않습니다. 서버에서 조회하지 못한 과거 출결을 임의로 채우지 않습니다.

## 오늘·지난 날짜 상태 선택

1. **오늘 → 달력에서 출결 조회**에서 오늘 또는 이전 날짜를 누릅니다. 앱을 설치하기 전인 **2026년 8월 31일**에도 상태를 지정할 수 있습니다.
2. 날짜 아래 **출석 / 조퇴 / 결석** 버튼을 누르면 바로 저장됩니다. 선택된 버튼은 색과 체크 표시가 켜집니다. 별도 입력창이나 저장 버튼은 없습니다.
3. 다른 상태를 누르면 바뀌고, 선택된 버튼을 다시 누르면 수기 상태가 해제됩니다. 날짜 칸과 월별 합계가 함께 갱신됩니다.
4. 시각은 앱이 확인한 Chrome 출결 기록만 표시합니다. 예전 버전에서 직접 입력한 시각은 표시하지 않으며, 해당 날짜의 상태를 다시 선택하거나 해제할 때 오래된 수기 시각도 정리합니다. 실제 확인 기록은 보존합니다.

상태를 직접 선택하는 것은 한국 날짜 기준 오늘까지 가능합니다. 미래 날짜에는 버튼을 표시하지 않습니다. 상태를 해제하면 앱이 확인한 기록 또는 현재 수업 요일·휴강 설정에 따른 표시로 돌아갑니다.

직접 선택한 상태는 앱에만 저장하며 사이트의 공식 출결을 수정하거나 Chrome 버튼을 누르지 않습니다. 오늘 자동 처리와 실제 입실·퇴실 시각, 클릭 보류, 오늘 로그에도 영향을 주지 않습니다.
