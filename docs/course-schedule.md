# 전 기간 단축수업과 당일 안내 · v0.9.12

원본 과정명세서(2026-08-31~2027-02-26)의 전체 120일·940시간을 기준으로 합니다. 2026-10-01 원본 시수 행을 다시 대조했습니다. 단축수업은 6시간 7일, 7시간 6일로 총 13일입니다. 일반 8시간 수업 107일과 합하면 940시간입니다.

## 적용 시간

사용자가 확인한 6시간 수업의 16시 종료·15:50:02 퇴실 기준을 전체 기간에 확대하라는 요청에 따라, 7시간 수업에는 17시 종료·16:50:02 퇴실 규칙을 적용합니다. 원본 PDF가 직접 제공하는 것은 날짜별 시수이며, 종료 시각은 이 적용 규칙입니다.

| 수업 시수 | 날짜 | 종료 | 자동 퇴실 시작 |
|---|---|---|---|
| 6시간 | 2026-08-31, 09-18, 10-06, 10-07 / 2027-02-19, 02-22, 02-23 | 16:00 | 15:50:02 |
| 7시간 | 2026-09-01, 10-26, 10-27, 10-28, 10-29, 12-08 | 17:00 | 16:50:02 |
| 8시간 | 나머지 수업일 | 원본에 종료 시각 없음 | 사용자 기본 설정 + 5초 (기본 17:50:05) |

휴강일 2026-09-23, 2027-02-05와 공휴일·대체공휴일, 추가 휴강일은 자동 출결에서 제외합니다. 단축수업 시각은 해당 날짜의 기본 퇴실 설정에 우선합니다. 입실 시간과 재시도 기간은 사용자 설정을 유지합니다. 기본 10분 재시도에서는 6시간 수업은 16시, 7시간 수업은 17시에 감시가 끝납니다. 완료 시 즉시 감시를 종료합니다.

## 당일 안내

- 오늘 탭의 그림 아래 별도 카드에 수업 시수·종료·자동 퇴실 시각을 표시합니다. 수업일이 아니거나 추가 휴강일이면 숨깁니다. 시간표 버튼은 그 날짜의 수업으로 연결됩니다.
- 단축수업 당일 입실 시작 시각(기본 08:30)에 한 번 알립니다. 그 이후 처음 앱을 열거나 재부팅하면 놓친 당일 안내를 보냅니다. 안내 알림 또는 휴대폰 알림이 차단돼 있으면 발송하지 않으며, 앱에서 허용하면 당일 다시 확인합니다.
- 이미 알린 날은 재실행·재부팅·알림 삭제 뒤에도 반복하지 않습니다. 다음 단축일에는 새로 알립니다. 자정에는 해당 알림이 만료됩니다.
- 출석 예약이 꺼져 있어도 수업 안내를 제공합니다. 카드와 알림에 자동 출결이 꺼져 있다는 사실을 표시합니다.
- 별도 알람은 로컬 알림만 발송합니다. Chrome·GPS·출석 감시를 시작하지 않습니다. 정확한 알람 권한이 없으면 일반 예약을 사용하여 안내가 다소 늦어질 수 있습니다. 강제 중지한 앱은 다시 열어야 예약이 복구됩니다.

## 일관된 출결 기준

자동 예약, 예약 활성화 직후 실행, 수동 퇴실 허용, 잠금 테스트 예약, 오늘 화면, 달력, 출결률, 완료 알림에 같은 날짜별 기준을 사용합니다. 기록 날짜가 단축일이면 나중에 조회해도 정상 퇴실이 조퇴로 바뀌지 않습니다. 사이트 분 단위 기록을 고려하여 조퇴 판정 기준에는 실행 여유 2초를 더하지 않습니다.

기존 서버 접속·클릭 횟수 제한과 결과 확인 방식은 유지합니다. 시각은 실행 시작 기준이고 실제 완료는 기기·Chrome·Wi-Fi 상태에 따라 늦어질 수 있습니다.
