# 입실·퇴실 완료 후 화면 끄기

## 동작

설정의 ‘출결 처리 화면’에서 두 기능을 각각 켜거나 끌 수 있다. 기본값은 둘 다 켜짐이다.

- 입실·퇴실 완료 후 화면 끄기: Chrome의 오늘 날짜 및 실제 완료 시각을 읽고 기록·완료 알림을 저장한 뒤 시스템 화면 잠금을 요청한다. 요청 접수와 실제 화면 꺼짐 관찰은 별도 로그다. Android 9 이상에서 지원한다.
- 자동 처리 중 간단한 안내 화면 표시: Chrome 위에 밝은 배경의 ‘출결 처리 중’ 페이지를 표시한다. ‘Chrome 화면 보기’ 버튼을 누르면 그 터치를 소비하고 Chrome을 보여준다. 다른 앱이나 잠금 화면으로 전환하면 안내 페이지를 해제한다.

직접 실행에서는 Chrome을 보여준다. 직접 실행으로 새 출결을 완료하면 화면을 끄지만, 이미 완료된 기록을 읽거나 기록만 조회할 때는 화면을 끄지 않는다. 오류·취소·시간 초과에는 안내 페이지를 제거하고 실패 안내를 확인할 수 있게 한다. 완료 알림은 화면을 끈 뒤에도 남는다. 시스템이 화면 끄기를 거절하더라도 이미 확인한 출결 성공을 취소하거나 재제출하지 않는다.

## 화면을 끈 채 처리하는 것과의 차이

현재 구현은 인증된 Chrome의 화면 요소를 읽고 클릭한다. 처리 중 디스플레이는 깨어 있으며 간단한 안내 페이지를 표시한다. 실제로 절전·잠금 상태를 계속 유지한 채 서버에 출결을 제출하는 구현은 아니다. 깨우기·시스템 인증 과정이나 제조사 시스템 표시가 잠깐 보일 수 있으며, Android가 PIN·지문을 요구하면 기존 인증 절차가 필요하다. 안내 페이지는 시스템 인증을 대신하거나 숨기지 않는다.

휴대폰 밝기는 변경하지 않는다. 안내 페이지는 출결 시도 동안만 존재하고, 최대 관찰 시간 후에도 독립 타이머로 해제된다. 네트워크 요청이나 자동 클릭 횟수는 늘리지 않는다.

## 근거

Android는 접근성 서비스에 [화면 잠금 동작](https://developer.android.com/reference/android/accessibilityservice/AccessibilityService#GLOBAL_ACTION_LOCK_SCREEN)을 제공한다. [접근성 오버레이](https://developer.android.com/reference/android/view/WindowManager.LayoutParams#TYPE_ACCESSIBILITY_OVERLAY)는 가려진 창의 접근성 읽기를 유지한다.

## 검증

Android 15 에뮬레이터와 실제 Chrome에서 7개 시나리오, 137개 검사를 통과했다. 에뮬레이터의 Chrome 요청은 CDP 로컬 응답과 DNS 차단을 사용하며 실제 출석 서버로 보내지 않았다.

| 시나리오 | 검사 수 | 확인 내용 |
| --- | ---: | --- |
| 자동 입실 | 22 | 밝은 처리 페이지 표시, 출결 완료 기록 뒤 실제 절전, 결과 알림 유지 |
| 자동 퇴실 | 25 | 처리 페이지 유지, 실제 Chrome 확인창 1회 클릭, 완료 뒤 절전 |
| 두 설정 끔 | 14 | 기존 Chrome 표시, 완료 후 화면 유지 |
| 이미 입실한 기록 조회 | 15 | 조회만 수행하고 화면 유지 |
| 퇴실 오류 | 24 | 오류 분류, 처리 페이지 제거, 화면 유지 |
| Chrome 화면 보기 | 23 | 실제 터치로 안내 페이지 닫기, 출결 완료 및 절전 |
| 처리 취소 | 14 | 안내 페이지 즉시 제거, 출결 제출 및 화면 잠금 없음 |

완료 기록부터 화면 꺼짐 관찰까지는 이 환경에서 입실 567ms, 퇴실 116ms였다. 기기별 시간 보장은 아니다. Java 단위 검사 103개와 로그 분석 Python 검사 21개도 통과했다. 최종 Android Lint는 오류 0개, 경고 8개다. 갤럭시의 Extend Unlock 및 제조사 절전 동작은 사용자 기기에서 별도 확인이 필요하다.

`ReplicaChecks`의 `-e processing true -e screen true -e automatic true` 옵션으로 자동 입실·퇴실을 시험한다. `-e reveal true`, `-e cancel true`는 안내 페이지 닫기·취소를 검사한다. 테스트 실행 전 [복제 사이트 절차](../fixtures/attendance/README.md)의 CDP 라우터와 DNS 차단을 먼저 구성해야 한다.
