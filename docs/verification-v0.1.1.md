# v0.1.1 검증 기록

- 실행: `gradlew.bat assembleDebug testDebugUnitTest lintDebug --no-daemon`
- JVM 테스트 12개 통과, Android Lint 오류 0개 / Gradle 업데이트 안내 1개
- v0.1.0 APK와 서명 인증서 일치, Android 15 / API 35 에뮬레이터 업데이트 설치 성공
- 기존 Wi-Fi 및 감시 설정 유지, 새 알림 설정 기본값 켜짐 확인
- 실제 설정 UI에서 끄기/켜기 및 각 상태의 앱 재실행 후 유지 확인
- 끄면 기존 결과 알림 제거 확인
- APK 업데이트 시 발생하는 감시 복구 알림으로 공통 `Notices.alert` 경로 확인: 끄면 표시 안 함, 다시 켜면 표시됨
- 입실·퇴실 완료와 퇴실 서비스의 결과 안내도 같은 알림 경로를 사용함을 코드에서 확인
- 알림 설정을 바꿔도 기존 Wi-Fi 및 감시 설정 유지
- 설정 화면 스크린샷 확인

UI 입력 직후 강제 종료한 첫 시도는 입력 처리가 끝나기 전에 종료되어 다시 수행했다. 화면의 스위치와 저장 값을 확인한 후 재실행한 검증에서 켜짐/꺼짐 유지가 통과했다.
에뮬레이터 부팅 중 런처 오류가 기록되었으며 출석 앱의 크래시는 관찰하지 않았다.

실제 계정의 입실·퇴실 요청은 실행하지 않았다. 실제 강의실 검증 범위는 [v0.1.0 검증](verification-v0.1.0.md)과 같다.
