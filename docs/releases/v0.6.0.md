# 출석 메이트 v0.6.0

퇴실은 설정 시각보다 **10초 뒤부터** 처리합니다. 기본 설정에서는 일반 예약과 임시 퇴실 테스트 모두 **17:50:10**에 시작하며 재시도 종료는 **18:00**으로 유지합니다. 버튼과 확인 대화상자 처리 전에도 시간 조건을 다시 확인합니다. 휴대폰의 날짜 및 시간은 자동 설정을 사용하세요.

- 출석 예약 **켜기 / 끄기** 버튼과 선택 상태 표시, 실제 감시 시간 안내
- 출석 시간 안에서만 자동 감시, 완료 또는 시간 종료 시 GPS 감시도 종료
- 오늘 화면에 확인된 입실·퇴실 기록만 표시하며 설정·앱 동작 로그 제외
- 월간 달력에 날짜별 출결 현황 표시, 날짜 선택 시 입실·퇴실 시간 조회
- 입실 시간 / 퇴실 시간 / 수업 요일을 나누어 설정
- 퇴실 재시도 시간 안에서 미퇴실 상태로 강의실을 벗어나면 알림
- 마지막 성공 업로드 기간의 로그 제외, 새 기록·수정된 판정과 메모만 업로드
- 실패한 업로드는 같은 파일로 재시도, 새 로그가 없으면 버튼 비활성화
- 감시 종료 직후 늦게 도착한 실행 요청의 앱 종료 문제 수정
