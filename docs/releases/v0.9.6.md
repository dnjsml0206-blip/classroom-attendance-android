## 이번 변경

- **설정 설명 간소화**: 카드 제목 옆 ‘도움말’을 눌렀을 때 스크롤 가능한 대화창으로 설명을 봅니다. 현재 값·권한 상태는 바로 표시하고, 퇴실 시각은 5초 여유를 포함한 실제 시작 시간으로 보여줍니다.
- **오늘 Wi-Fi 상태 터치**: 등록된 네트워크로 연결을 시도합니다. 여러 개면 먼저 고릅니다. 접근성과 화면 읽기가 가능한 경우 정확히 일치하는 SSID·연결 버튼을 각각 한 번 선택합니다. 화면을 읽지 못하면 6초 후 직접 선택 안내로 끝나며, Wi-Fi가 꺼져 있거나 인증이 필요하면 휴대폰 화면에서 진행합니다. 실제 기본 인터넷 연결이 확인돼야 ‘대기 중’으로 바뀝니다.
- **수동 실행 진단**: ‘조건 미충족’ 대신 시간 전·수업일 아님·Wi-Fi 문제·접근성 미연결·다른 화면 작업 중을 구분합니다. 해당 시점 설정 시각과 다음 예약도 남깁니다.
- **설정 변경 진단**: 시간·요일 변경 전후와 재예약 시각을 기록합니다. 오늘 출석 로그에는 설정 내용을 넣지 않습니다.
- **출석 결과 구분**: 앱 클릭 후 확인한 기록과 이번 실행에서 클릭 없이 발견한 기존 기록을 나누고, 사이트에 표시된 날짜·입실·퇴실 시각을 진단 로그에 남깁니다. 기존 기록을 누가 처리했는지는 단정하지 않습니다.
