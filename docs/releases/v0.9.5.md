# 출석 메이트 v0.9.5

제작자용 APK: **classroom-attendance-0.9.5-creator-debug.apk**

기존 앱을 삭제하지 말고 APK로 업데이트하세요. 이전 릴리스와 같은 서명을 사용하며 versionCode 20입니다. 설치 후 앱을 한 번 열어 출석 예약과 접근성 연결 상태를 확인하세요.

## 이번 변경

- 자동 처리 중에는 간단한 **출결 처리 중** 페이지를 보여줍니다. **Chrome 화면 보기** 버튼으로 진행 화면을 확인할 수 있습니다.
- 입실·퇴실의 오늘 날짜와 실제 완료 시각을 확인하고 기록·완료 알림을 남긴 뒤 화면을 끕니다. 클릭 접수만으로 화면을 끄지 않습니다.
- 설정의 **출결 처리 화면**에서 안내 페이지와 완료 후 화면 끄기를 각각 켜거나 끌 수 있습니다. 기본값은 둘 다 켜짐입니다.
- 오류·취소·시간 초과에는 안내 페이지를 닫고 화면을 유지합니다. 이미 완료된 출결 기록만 직접 조회할 때도 화면을 끄지 않습니다.
- 퇴실 확인창이 나타나고 최소 600ms 지난 뒤 Chrome의 실제 확인 버튼을 한 번 누릅니다. 확인 요청·창 사라짐·사이트 완료 시각을 구분해 기록합니다.
- 확인창이 남거나 재등장하는 경우와 후속 Wi-Fi·인증·서버 오류를 구분해 기록하고 멈춥니다. 미확인 요청을 반복 제출하지 않습니다.

## 동작 조건

현재 Chrome 자동 조작은 처리 중 화면이 켜지고 잠금이 해제되어 있어야 합니다. 처리 내내 잠금을 유지하는 방식은 아닙니다. Extend Unlock 등 기존 잠금 처리 설정을 사용하며 PIN·지문 재인증이 필요하면 시스템 인증이 필요합니다. 완료 후 화면 끄기는 Android 9 이상에서 지원합니다.

## 확인된 범위

Java 단위 검사 103개와 로그 분석 검사 21개를 통과했습니다. 실제 출석 서버에 요청하지 않고 Android 15 에뮬레이터와 실제 Chrome에서 로컬 응답으로 시험했습니다.

- 화면 처리: 7개 시나리오, 137개 검사. 자동 입실·퇴실 후 실제 화면 꺼짐, 완료 알림 유지, 설정 끄기, 기존 기록 조회, 오류, 안내 페이지 닫기, 취소를 확인했습니다.
- 퇴실 확인창 보완: 별도의 6개 시나리오, 98개 검사. 정상 확인·Wi-Fi 거부·미분류 안내·확인창 재등장·완료 시각 미저장·입실 회귀를 확인했습니다.
- Android Lint: 오류 0개, 경고 8개. 배포 버전 번호 변경 후 APK를 다시 빌드하고 기존 서명과 버전을 확인했습니다.

갤럭시의 Extend Unlock, Chrome 버전 및 실제 출석 서버의 저장 결과는 사용자 기기에서 확인이 필요합니다.
