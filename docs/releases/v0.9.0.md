# v0.9.0 · 대체 클릭 시험과 자동화 설정

- 진단 · 제작자용 카드를 설정 맨 아래로 옮겼습니다.
- 알림 후 직접 해제 선택지를 제거하고 기본값을 Extend Unlock · 신뢰 상태로 변경했습니다. 이전 알림 전용 선택도 Extend Unlock으로 적용됩니다.
- 오늘 화면 하단에 대상 Wi-Fi 인식 상태를 표시합니다: 대기 중 / 와이파이 미연결.
- 실제 출결 시험을 대체 클릭 시험으로 교체했습니다. Chrome의 휴대폰 내부 시험 버튼을 자동으로 누르고 화면 변경까지 확인해야 성공입니다. 성공·실패와 이유를 앱·알림에 표시하고 업로드 로그에도 남깁니다.

## 설치와 시험

1. `classroom-attendance-0.9.0-creator-debug.apk`를 기존 앱 위에 설치합니다.
2. 설정 → 잠금 중 처리 방식에서 Extend Unlock 선택과 휴대폰 신뢰 설정을 확인합니다. 일반 출석에는 출석 예약·자동 클릭·접근성 연결이 필요합니다.
3. 설정 맨 아래 → 진단 · 제작자용 → 잠금 상태 테스트 열기 → 지금 대체 클릭 시험을 누릅니다. Chrome 시험 버튼은 직접 누르지 마세요.
4. 즉시 시험이 성공하면 15초 후 실행을 선택하고 대체 클릭 시험 예약을 누른 뒤 화면을 끕니다. 결과 알림 또는 앱에서 성공·실패를 확인합니다.
5. 로그 확인 · GitHub 업로드로 기록을 올립니다. 직접 화면을 켰거나 잠금을 해제했다면 결과에 함께 기록하세요.

대체 시험은 강의실 Wi-Fi와 출석 시간 밖에서도 가능합니다. 성공은 Chrome 버튼 자동 클릭과 화면 변경 확인이며, 실제 서버 출결 성공이나 보안 잠금의 무인 해제를 보장하지 않습니다. PIN·지문 재인증이 필요하면 시스템 인증을 완료해야 합니다.

검증: 단위·분석·Android 기능 검사 262개 통과. 에뮬레이터에서 즉시 및 화면 꺼짐 예약 후 실제 Chrome 버튼 클릭을 확인했습니다.
