# v0.9.15 · 출결 관리 개선과 완료 후 잠금 모드

- 오늘 화면의 출결 기록 확인을 입실 상태 옆으로, 달력 버튼을 오늘 출결 제목 옆으로 옮기고 불필요한 설명을 정리했습니다.
- 현재 출결률은 종료된 수업일만 계산합니다. 기록 없는 지난 수업일은 사용자 요청대로 출석 처리하며, 지각·조퇴 합산 3회당 결석 1일을 반영합니다. 80% 기준 추가 결석 또는 지각·조퇴 가능 횟수를 표시합니다.
- 달력에서 지각·조퇴를 각각 선택할 수 있습니다. 월 1회 누적 휴가와 잔여 휴가 관리를 추가했습니다. 휴가는 앱 기록이며 기관에 휴가를 신청하지 않습니다.
- 설정 → 출결 처리 화면에 완료 후 잠금 모드와 잠금 모드만 테스트를 추가했습니다. 출결 완료 확인 후 시스템 전원 메뉴의 잠금 모드를 한 번 누르고 화면을 끕니다. 항목을 읽지 못하면 일반 화면 끄기로 마무리하고 원인을 기록합니다.
- 잠금 모드 이후 첫 해제에는 PIN·패턴·비밀번호가 필요합니다. 지문 및 Extend Unlock은 그 첫 해제를 대신할 수 없으며, Wi-Fi 재연결만으로 해제되지 않습니다. PIN 해제 후에도 신뢰 조건과 최대 4시간 제한이 적용됩니다.

기존 앱 위에 제작자용 APK를 설치하세요. 이전 v0.9.14 로컬 변경을 모두 포함하며 기존 서명을 유지했습니다. 갤럭시 기기별 메뉴 호환성은 설정의 잠금 모드만 테스트로 확인해 주세요.
