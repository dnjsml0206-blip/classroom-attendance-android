# v0.9.20 — 자동출결 OFF에서 Chrome 기록 자동 수집

기존 출석 메이트 앱에 통합한 기능입니다. 별도 테스트 앱이 아닙니다. 이전에 구현한 Extend Unlock 선택 설정도 포함합니다.

## 사용 방법

1. 기존 앱을 삭제하지 않고 APK로 업데이트합니다.
2. 접근성의 '출석 메이트 · Chrome 출석' 연결을 유지합니다.
3. 출석 예약을 끄거나 Chrome 자동 클릭을 끕니다. 오늘 화면에 '기록 수집 중'이 표시됩니다.
4. 사용자가 Chrome에서 출결 페이지를 열어 직접 입실/퇴실합니다.
5. 완료 시각이 표시될 때까지 잠시 기다립니다. '입실 기록 저장됨' 또는 '퇴실 기록 저장됨' 알림과 앱 달력에서 결과를 확인합니다.

## 동작 경계

- Android의 Chrome 화면 변경 이벤트를 받아 250ms 후 화면을 읽습니다. 주기적인 페이지 새로고침이나 서버 요청은 하지 않습니다.
- 자동출결 OFF에서는 자동 출결용 예약 알람과 위치 감시 서비스를 중단합니다. 수집에는 접근성 연결만 필요합니다. 단축수업 안내 등 독립된 알림은 기존 설정을 따릅니다.
- 앱이 Chrome을 열거나 출결 버튼/확인 버튼을 누르거나 화면을 깨우거나 잠금을 조작하지 않습니다. 사용자가 앱의 수동 입실/퇴실 버튼을 명시적으로 누르는 기존 기능은 유지됩니다.
- 읽기 전용 수집에는 등록 Wi-Fi·위치·정확한 알람·Extend Unlock 설정을 요구하지 않습니다. 사이트의 출결 처리 자체는 강의실 Wi-Fi 등 서버 조건을 따릅니다.
- Chrome의 정확한 출결 주소, 보이는 웹 화면, 오늘 날짜, 완료된 시각을 확인한 경우만 저장합니다. 주소가 숨겨져 있거나 화면을 즉시 닫아 내용을 읽을 수 없으면 저장하지 못할 수 있습니다.
- 입실/퇴실 완료 시각이 같으면 중복 알림과 로그를 만들지 않습니다. 부분적으로 보이는 화면으로 기존 퇴실 시각을 지우지 않습니다. 기존 확정 시각과 충돌하면 자동으로 덮어쓰지 않습니다.
- 기록의 출처는 PASSIVE_CHROME_OBSERVATION으로 남깁니다. 사용자가 직접 눌렀는지 서버에서 이미 처리된 것인지는 단정하지 않습니다.
- Chrome 쿠키·비밀번호·이름·화면 원문을 진단 로그로 내보내지 않습니다.

## 검증

- 단위 테스트 228개 통과, 기존 앱 및 테스트 빌드 성공.
- Android 15 에뮬레이터의 실제 Chrome에서 연동 검사 23개 통과: OFF 전환, 입실/퇴실 저장, 중복 방지, 기존 기록 보존, 자동 동작 미발생 확인.
- 로컬 응답으로만 시험했으며 외부 DNS 차단과 요청 가로채기를 적용했습니다. 실제 출결 서버에 시험 요청을 전송하지 않았습니다.
- 초기 시험은 테스트 서버 연결 실패, 두 번째는 에뮬레이터의 Chrome 로딩 지연으로 시간 초과했습니다. 환경 준비 후 동일 APK와 동일 검사로 최종 통과했습니다. 실제 휴대폰의 Chrome·배터리 설정에 따른 기록 수집은 사용자 확인이 필요합니다.
- 기존 버전과 서명 인증서가 동일함을 확인했습니다. APK SHA-256: `89179daae787b07f0b16a6464a47d21f05a3cffb7054cf21bd23d626b7300971`.
