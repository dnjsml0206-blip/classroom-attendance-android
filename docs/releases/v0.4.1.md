# 출석 메이트 v0.4.1 · 방법별 간단 테스트 안내

잠금 상태 테스트 메뉴에서 방식을 선택하면 **준비 → 실행 → 성공 확인** 안내가 바로 바뀝니다. 7가지 방식 각각의 휴대폰 설정, 실행 순서와 결과 판단 기준을 짧게 확인할 수 있습니다.

- 화면 깨우기, Extend Unlock, Bluetooth 기기, 장소, 신체 활동, 시스템 인증, 서버 연결 진단별 안내
- 잠금 화면에 멈춤, 재인증 요구, Bluetooth 연결 여부 등 방식별 확인 사항
- ‘처음 한 번 확인할 설정’에서 접근성·알람·알림 준비 및 결과 기록 요령
- 서버 진단 성공은 연결 응답만 의미하며, 실제 출결 시도는 기본 OFF

**classroom-attendance-0.4.1-debug.apk**를 기존 앱 위에 업데이트한 뒤 **설정 → 임시 메뉴 → 잠금 상태 테스트 열기**에서 확인하세요. 방식별 안내를 읽고 ‘예약하고 화면 끄기’를 누르면 됩니다.

검증: 단위 테스트 38개, 기존 잠금 메뉴 검사 12개 통과. 7가지 안내와 공통 도움말을 실제 APK에서 확인했습니다. 린트 오류 0개, 동일 서명 업데이트 설치 확인.
