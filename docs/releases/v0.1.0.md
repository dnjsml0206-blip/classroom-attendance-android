# 출석 메이트 v0.1.0 · 초기 테스트 APK

기본 Wi-Fi는 **TACADEMY_5G**이며 설정에서 다른 Wi-Fi를 추가·삭제할 수 있습니다.

포함 기능:
- 강의실 위치·Wi-Fi 감시와 미연결 알림
- 수업 요일·입실 시간·휴강일 설정
- 17:50 퇴실 예약
- 앱 내 인증, 출석 기록 조회 및 자동 입퇴실
- 실제 기록 재확인과 중복 요청 방지

설치 파일: **classroom-attendance-0.1.0-debug.apk** (Android 8.0 이상).

처음에는 조회 모드입니다. 앱 안에서 본인에게 발급된 인증 링크를 열어 인증을 저장하고,
위치·알림·알람 권한을 설정한 뒤 감시를 시작하세요.
기록이 정상 조회되면 설정에서 자동 처리를 켤 수 있습니다.

Chrome 인증은 앱과 자동 공유되지 않습니다.
Wi-Fi를 켜는 동작은 휴대폰 자동 연결이나 갤럭시 모드 및 루틴을 사용합니다.
실제 본인 계정과 강의실 Wi-Fi에서 자동 출석 동작은 추가 검증이 필요합니다.

JVM 테스트 12개 통과, Android Lint 오류 0개.
테스트용 debug 서명 APK이며 정식 스토어 배포 버전은 아닙니다.
