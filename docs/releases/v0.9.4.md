# 출석 메이트 v0.9.4

제작자용 APK: **classroom-attendance-0.9.4-creator-debug.apk**

기존 앱을 삭제하지 말고 APK로 업데이트하세요. 이전 릴리스와 같은 서명을 사용하며 versionCode 19입니다. 설치 후 앱을 한 번 열어 출석 예약과 접근성 연결 상태를 확인하세요.

## 이번 변경

- 이미 입실·퇴실한 시각은 새 클릭을 위한 대기 없이 읽습니다. 정확한 출결 주소와 오늘 날짜를 확인하는 조건은 유지합니다.
- Chrome에서 시각을 읽기 전에 출석 앱으로 돌아오면 대기를 종료하고 버튼을 복구합니다. 시각을 확인하지 못했으면 버튼 아래에 미확인 안내를 표시합니다. 너무 일찍 돌아오면 실제 시각은 아직 표시할 수 없습니다.
- 클릭 전 복귀 후 자동 재시도는 2분 뒤부터 가능하며, 수동 요청은 기존 3초 간격을 유지합니다. 이미 클릭을 보낸 경우에는 기록과 보류를 유지해 중복 처리를 막습니다.
- 달력은 **출석·조퇴·결석** 버튼을 누르면 바로 저장하고, 같은 버튼을 다시 누르면 해제합니다. 별도 입력창과 저장 버튼을 제거했습니다.
- 달력의 시각은 **앱이 Chrome에서 확인한 기록이 있을 때만** 표시합니다. 시간 입력창과 기존 수기 시각 표시는 제거했으며 실제 확인 기록은 보존합니다.
