# v0.9.21 — 오늘 화면과 자동출석 설정 정리

- 오늘 화면 상단을 날짜·요일 / 출결·시간표 / Wi-Fi 상태 순서로 배치했습니다.
- 설정의 앱 이름·버전·제작자용 안내 카드를 제거했습니다. 비밀번호로 여는 진단 메뉴는 유지합니다.
- 일반 예약의 잠금 방식은 Extend Unlock 선택에 따라 정해집니다. 선택하면 신뢰 상태의 시스템 잠금 해제를 요청하고, 선택하지 않으면 화면만 깨웁니다. 화면이 켜져도 PIN·지문·밀어서 해제가 필요한 상태면 자동으로 통과하지 않습니다.
- 과거 시스템 인증 요청(AUTH) 선택은 일반 예약에서 더 이상 사용하지 않습니다. 제작자 진단의 실험 방식과 분리됩니다.
- 출결 처리 화면 카드를 자동출석 탭 맨 아래로 이동했습니다. 안내 화면·완료 후 화면 끄기·잠금 모드 기본값은 모두 ON이고, 예약 또는 자동 클릭을 켤 때도 ON으로 설정합니다. 이후 개별 옵션을 끌 수 있습니다. 잠금 모드는 다음에 PIN·패턴·비밀번호로 한 번 해제해야 합니다.
- 입실 처리 안내에는 아침 일러스트, 퇴실 안내에는 야간 일러스트를 사용합니다. 준비 단계와 완료 시각 확인 단계를 구분하며, 완료 전 성공으로 표시하지 않습니다. Chrome 화면 보기와 깨우기 중단 버튼을 유지합니다.
- 자동출결 OFF의 Chrome 기록 수집 기능은 유지됩니다.

- 단위 테스트 229개 통과. 기존 앱과 Android 테스트 APK 빌드 성공.
- 에뮬레이터 설정 전환 검사 4개 통과, 8개 화면 캡처 및 직접 검토 완료.
