# v0.9.19 · 출석 연결과 자동출석 설정 통합

- 설정 최상단에 출석 주소 붙여넣기·저장·Chrome 열기를 추가했습니다. 기존 Chrome 인증을 사용하며 저장만으로 인증 완료나 자동출석 활성화로 표시하지 않습니다. 지원하는 SK플래닛 출결·인증 페이지를 검증하고 HTTP를 HTTPS로 정규화합니다.
- 연결 탭을 자동출석으로 변경하고 준비 확인, 예약, 시간, 휴강일, Wi-Fi, 강의실 위치, 잠금 처리, Chrome 인증을 모았습니다. 일반 설정에는 출석 주소, 알림, 앱 정보와 제작자 진단을 배치했습니다.
- 제작자 진단은 비밀번호로 아래에 펼칩니다. 접기, 탭 이동, 앱 이탈 시 다시 잠깁니다. 사용자 요청의 UI 접근 제한이며 기기 인증이나 암호화 저장소를 대체하지 않습니다.
- 오늘 화면의 인사말을 한 줄 Bold로 키우고 단축수업 제목 아래에 배경 없이 배치했습니다. 일반 수업일에는 인사말만 표시합니다. 출결·시간표 달력에서 선택 날짜의 과목과 종료 시각을 함께 확인합니다.
- 새 Wi-Fi 준비와 실제 잠금 해제 신호를 받으면 로컬 60초 확인 대기를 건너뜁니다. 신뢰 상태가 늦게 반영되는 경우 최대 8초만 로컬 상태를 확인합니다. 서버 최소 3초 간격, 자동 각 3회, 하루 20회 및 결과 미확인 보류 제한은 유지합니다.
- 잠금 과정 진단 정보를 보강했습니다. 업로드된 10/7 로그는 v0.9.15이며, 최신 갤럭시에서 잠금 모드 성공 여부는 업데이트 후 확인이 필요합니다.

수동 입실·퇴실은 기존처럼 출석 예약과 자동 클릭 설정이 꺼져 있어도 가능합니다. 지정 Wi-Fi, 정확한 위치, Chrome 접근성 및 실행 시각·수업일 조건은 적용됩니다. Extend Unlock·정확한 알람·강의실 위치 등록은 수동 실행의 필수 조건이 아닙니다.

**보류:** Extend Unlock의 출석 시간별 ON/OFF와 평상시 잠금 유지 전환은 구현하지 않았습니다. 잠금 모드 이후 첫 해제에는 PIN·패턴·비밀번호가 필요하며 다음 예약 시각에 앱이 강한 잠금을 자동으로 풀 수 없습니다.

검증: 최종 주소 기능 단위 검사 218개 및 설정·주소·비밀번호 기기 검사 25개 통과. 관련 변경 단계에서 준비 상태 기기 검사 15개, 기존 깨우기 검사 43개, 단축수업 검사 16개 및 낮·밤/일반·단축수업 화면 캡처 검토를 완료했습니다. 에뮬레이터 검증에서는 실제 출석 서버 요청을 보내지 않았습니다.
