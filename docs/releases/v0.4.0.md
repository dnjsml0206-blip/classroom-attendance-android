# 출석 메이트 v0.4.0 · 잠금 상태 테스트 임시 메뉴

설정 맨 위에 잠금 상태 테스트 메뉴를 추가했습니다. 직접 실행하고 되는지 안 되는지 기록할 수 있습니다.

- 화면 깨우기, Extend Unlock, 신뢰하는 Bluetooth 기기, 신뢰하는 장소, 신체 활동 감지, 시스템 인증, 잠금 유지 서버 진단 등 7가지 선택
- 15·30·60초 뒤 일회성 실행 또는 지금 테스트
- 잠금·인증 상태, 자동/수동 진입, 시스템 해제 결과, Chrome 화면 확인 로그
- 성공·부분 성공·실패와 메모 저장, 최근 결과 전체 복사
- 기본은 조회 테스트. 실제 출결 시도 스위치를 켜면 기존 시간·Wi-Fi·예약·자동 클릭 조건을 적용
- 서버 전용 인증/API 출결은 아직 미연동. 잠금 유지 방식은 등록 Wi-Fi의 HTTPS 연결 진단만 제공
- 테스트 취소·만료·재부팅/업데이트 후 오래된 테스트 실행 차단

설치: **classroom-attendance-0.4.0-debug.apk**를 기존 앱 위에 업데이트하세요.

설정 → 잠금 상태 테스트 열기 → 방법 선택 → 예약하고 화면 끄기 순서로 확인합니다. 확인 후 성공 여부를 저장하고 결과 전체 복사로 전달할 수 있습니다.

에뮬레이터에서 화면 꺼짐 후 Chrome 진입, 인증 필요 시 신뢰 경로 보류, 정상 PIN 인증 뒤 Chrome 연결을 확인했습니다. 실제 Extend Unlock 기기·장소·신체 활동 감지와 제조사별 동작은 사용자 휴대폰에서 비교해야 합니다. 평소 출결 예약에 테스트 방법이 자동으로 적용되지는 않습니다.

검증: 단위 테스트 38개, 임시 메뉴 12개, 예약·알림 12개 통과. 린트 오류 0개. 동일 서명 업데이트 설치 확인.
