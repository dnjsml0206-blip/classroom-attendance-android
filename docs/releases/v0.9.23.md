# v0.9.23 · 입실 지연 및 잠금 완료 판정 보완

- Wi-Fi 연결 직후 인증이 유지된 잠금화면에서 멈추던 문제를 수정했습니다. Extend Unlock 선택 여부와 관계없이 Android가 인증 유효 상태로 판단하면 잠금화면 닫기를 요청하고 즉시 출결로 이어갑니다. PIN·지문 재인증을 우회하지 않습니다.
- 이미 인증 잠금 상태라면 추가 잠금 시도를 종료합니다. 전원 메뉴 방식이 실패하고 아직 잠금화면이 표시 중인 경우에만 식별 가능한 시스템 자물쇠의 길게 누르기를 한 번 시도합니다. 아이콘을 찾지 못하면 임의 좌표 드래그를 하지 않습니다.
- 실제 인증 잠금, 시도한 방법, 화면 꺼짐을 별도로 기록합니다. 인증 잠금 관찰만으로 강한 잠금 모드의 생체인증 차단까지 보장하지 않습니다.
- 자동출석 준비 목록의 마지막 항목에 Chrome 자동 클릭(Extended Unlock)을 모으고 중복 선택 카드를 통합했습니다.
- 첫 설치 때 세 가지 사용 방법을 안내합니다. 자동출석은 선택 사항이며, 기존 Chrome 직접 출석 방식도 사용할 수 있습니다.
