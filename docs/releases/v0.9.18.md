# v0.9.18 · 빠른 최초 설정과 출결 후 잠금 보완

- 설정 → 빠른 설정 시작하기에서 완료된 항목을 건너뛰고 필요한 휴대폰 설정만 이어서 안내합니다. 기존 Wi-Fi·시간 설정은 보존하며, 권한 허용·PIN 입력·신뢰 장소 등록은 직접 확인합니다. Chrome 인증과 Extend Unlock은 메뉴 방문만으로 완료 표시하지 않습니다.
- 위치와 알림을 함께 요청한 뒤 알림만 거부해도 자동으로 다시 요청하지 않습니다. 사용자가 알림 허용하기를 다시 눌렀을 때만 재요청합니다. 출석 예약은 마지막 확인 후 켜집니다.
- 전원 메뉴가 별도 시스템 창에 나타나도 잠금 항목을 찾도록 보완했습니다. 정확한 잠금 후보를 안정적으로 읽었을 때 한 번만 클릭하고, 버튼 탐색·클릭 전달·인증 잠금·화면 꺼짐을 구분해 표시하고 기록합니다.
- 설정 → 출결 처리 화면 → 잠금 모드만 테스트에서 실제 출결 없이 시험할 수 있습니다. 잠금 항목이 없거나 확인되지 않으면 일반 화면 끄기로 마무리하며 잠금 모드 성공으로 표시하지 않습니다.
- 지각·조퇴는 매회 결석 ⅓일로 즉시 반영합니다. 현재·최종 예상 출결률과 80% 기준 남은 결석 여유를 함께 수정했습니다. 이전 v0.9.16·v0.9.17 로컬 변경을 모두 포함합니다.

기존 앱 위에 제작자용 APK를 설치하세요. 이전 APK와 서명이 같아 기존 설정과 기록을 유지하며 업데이트할 수 있습니다.

잠금 모드 이후 첫 해제에는 PIN·패턴·비밀번호가 필요합니다. Wi-Fi 재연결만으로 해제되지는 않습니다. 이번 잠금 검증은 API 35 에뮬레이터에서 수행했으며, 사용자의 최신 잠금 실패 로그가 없어 해당 갤럭시의 정확한 실패 원인은 아직 확정하지 못했습니다.

검증: 단위 테스트 209개, 설정 화면 검사 21개, 실제 시스템 잠금 검사 12개 통과. 잠금 검사 중 출결 사이트 요청은 0회이며, 전원 메뉴와 잠금 클릭은 각각 1회였습니다. lint 오류 0개, 기존 경고 12개.
