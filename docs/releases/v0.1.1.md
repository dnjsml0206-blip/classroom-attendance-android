# 출석 메이트 v0.1.1 · 알림 설정

설정 화면 맨 위에 **알림 → 입실·퇴실 알림** 스위치를 추가했습니다.

- 기본값은 켜짐이며 기존 설치를 업데이트해도 기존 알림 동작을 유지합니다.
- 끄면 입실·퇴실 결과 및 출석 확인 요청 알림을 보내지 않고, 표시 중인 결과 알림도 지웁니다.
- 앱을 종료하거나 다시 실행해도 선택이 유지됩니다.
- 알림을 꺼도 자동 출석은 동작합니다. Wi-Fi 미연결과 감시 상태 알림은 별도로 표시됩니다.

설치 파일: **classroom-attendance-0.1.1-debug.apk** (Android 8.0 이상).
기존 앱 위에 업데이트 설치할 수 있습니다. 사이트 인증과 출석 설정은 유지됩니다.

실제 강의실 Wi-Fi에서 자동 출석은 추가 검증이 필요한 초기 테스트 버전입니다.

JVM 테스트 12개와 Android Lint 검사 통과. 에뮬레이터에서 업데이트 설치, 알림 켜기/끄기, 재실행 후 유지 및 알림 제거·재개를 확인했습니다.
