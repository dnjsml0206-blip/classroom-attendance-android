# 출석 메이트 v0.2.0 · Chrome 인증과 시간 예약

기존 휴대폰 Chrome의 인증을 사용하는 버전입니다.

- 입실 기본 08:30–09:30; 입실 기록 확인 즉시 감시 종료
- 퇴실 기본 17:50; 실패 시 Wi-Fi 연결 요청, 완료 시 종료
- 입실·퇴실 시각, 수업 요일과 재시도 시간 변경
- 기본 반경 30m 및 기존 150m 기본값 업데이트
- 달력으로 휴강일 추가·삭제
- 오늘 탭을 출결 현황·오늘 로그로 정리; 날짜별 기록 달력 조회
- 인텔리전트 Wi-Fi 설정 진입
- 결과 알림 ON/OFF 유지

설치 파일: **classroom-attendance-0.2.0-debug.apk**. 기존 버전 위에 업데이트할 수 있습니다.

연결 탭에서 **Chrome 접근성**, **위치 항상 허용**, **정확한 알람**, **알림 권한**을 설정하고, 설정에서 **자동 클릭**과 **출석 예약**을 켜 주세요.

**잠금 화면에서는 알림을 눌러 잠금을 해제해야 합니다.** 퇴실 실패 재시도는 기본 10분이며 변경 가능합니다.

달력에는 앱이 확인한 기록을 표시합니다. 이전 전체 출결은 Chrome에서 확인하세요. 실제 인증된 Chrome·강의실 Wi-Fi 및 갤럭시 메뉴 이동은 추가 검증이 필요한 테스트 버전입니다.

검증: 단위 테스트 23개·Android 기기 테스트 6개 통과, 린트 오류 0개. 휴강일 달력과 시간 변경 저장도 확인했습니다.
