# 출석 메이트 v0.2.1 · 완료 알림 항상 유지

입실과 퇴실이 사이트 기록으로 확인되면 각각 완료 알림을 남깁니다.

- 기존 결과 알림 OFF 설정과 관계없이 완료 알림 표시
- 날짜별·입실/퇴실별 알림을 분리해 서로 덮어쓰지 않음
- 알림을 눌러 앱을 열거나 감시가 끝나도 완료 알림 유지; 직접 삭제 가능
- 설정의 결과 알림 OFF 스위치를 항상 표시 안내와 휴대폰 알림 설정 버튼으로 교체
- 휴대폰에서 앱 알림 또는 결과 알림 채널이 차단되어 있으면 설정에서 안내

자동 출석 조건은 그대로입니다. 설정한 수업일과 시간대에 화면이 켜지고 잠금이 해제되어 있으며, 등록한 Wi-Fi·기존 Chrome 인증·접근성·자동 클릭·출석 예약과 필요한 권한이 준비되어 있어야 합니다.

설치 파일: **classroom-attendance-0.2.1-debug.apk**. 기존 버전 위에 업데이트할 수 있습니다.

휴대폰의 알림 허용이 필요합니다. 실제 수강생의 인증된 Chrome과 강의실 Wi-Fi에서의 출석, 갤럭시별 메뉴 이동은 실기기 확인이 필요한 테스트 버전입니다.

검증: 단위 테스트 23개, Android 예약·알림 테스트 12개 통과. 린트 오류 0개. 기존 APK와 동일한 서명으로 업데이트 설치를 확인했습니다.
