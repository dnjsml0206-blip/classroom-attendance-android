# 출석 메이트 v0.3.0 · 시간에 따라 바뀌는 오늘 화면

입실 시간에는 따뜻한 교실 일러스트를 보여 주고, 퇴실이 가까워지면 야간 대시보드로 자동 전환합니다.

- 낮: 아이보리 배경, 살구색 포인트, 햇살이 들어오는 교실 일러스트
- 밤: 짙은 남색 배경, 밝은 파란색 포인트, 조명이 켜진 책상 일러스트
- 기본 16:50 전환: 설정한 퇴실 시각 17:50의 1시간 전
- 퇴실 시각 변경 시 전환 시각도 자동 변경; 입실 시간과 겹치면 입실 종료 후 전환
- 자정에는 밝은 테마로 복귀하고 새 날짜의 기록을 표시
- 화면을 열어 둔 상태와 앱 복귀 시 테마 갱신; 별도 백그라운드 감시 추가 없음
- 오늘 출결 현황·달력 조회·로그 유지; 완료가 확인되지 않은 퇴실 시각은 기록으로 표시하지 않음
- 야간 화면의 상태 표시줄·하단 버튼 색상도 함께 변경

설치 파일: **classroom-attendance-0.3.0-debug.apk**. 기존 v0.2.1 위에 업데이트할 수 있습니다.

입실·퇴실 완료 알림은 계속 항상 표시합니다. Chrome 출석은 기존처럼 등록 Wi-Fi·예약 시간·필요 권한·Chrome 인증과 화면 잠금 해제가 필요합니다. 실제 강의실 환경에서의 확인이 필요한 테스트 버전입니다.

검증: 단위 테스트 30개, 화면 전환 테스트 10개, 예약·알림 테스트 12개 통과. 린트 오류 0개. 이전 APK와 같은 서명 및 업데이트 설치 확인.
