# v0.9.24 · 자물쇠 우선 잠금과 퇴실 재개 알림

- 상단의 식별된 시스템 자물쇠를 제자리에서 1.2초간 길게 누릅니다. 드래그하지 않습니다.
- 실제 인증 잠금을 확인하지 못하면 전원 메뉴의 잠금 모드를 한 번 시도합니다. 이미 인증 잠금 상태이면 추가 동작을 생략합니다.
- 퇴실 시 인증이 필요하면 “자동 퇴실 대기 · 잠금을 해제해 주세요” 알림을 표시합니다. 알림을 눌러 시스템 인증을 마치면 등록된 강의실 Wi-Fi에서 퇴실을 이어갑니다.
- 지난 날짜·예약 꺼짐·출결 완료·휴강일·퇴실 시각 전 알림은 실행하지 않습니다. 기존 중복 클릭 방지 조건을 유지합니다.
- Wi-Fi 재연결만으로 Extend Unlock이 복구된다고 가정하지 않고 실제 Android 잠금 상태를 확인합니다.

## 설치 및 검증
기존 앱에 덮어 설치하는 제작자용 APK입니다. versionCode 39, 기존 서명 유지.
단위 테스트 238개 통과, Lint 및 APK 빌드 성공. 실제 서버 출결 요청으로 시험하지 않았습니다.
Galaxy 실기기에서 자물쇠 인식·길게 누르기 및 알림 인증 후 재개는 추가 확인이 필요합니다.
인증 잠금 관찰만으로 생체인증까지 차단되는 강한 잠금 모드라고 판단하지 않습니다.
