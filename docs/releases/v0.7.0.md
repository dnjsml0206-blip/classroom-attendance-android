# v0.7.0 · 입실 시험용 제작자 APK

출결 버튼 요청과 결과 확인을 일반 예약에서도 기록하고, 반복 접속을 제한했습니다. 이번 APK는 2026년 9월 15일 입실 시험에 사용할 제작자용이며 비공개 저장소에서 제공합니다.

## 포함한 변경

- 모든 앱 내 Chrome 출결·인증 페이지 열기에 3초 간격과 하루 20회 한도를 적용합니다. 자동 입실·퇴실은 각각 최대 3회, 재시도는 2분·5분 후이며 사이트 오류나 결과 미확인 시 자동 재접속을 중단합니다.
- 버튼·확인 요청을 반복하지 않고, 일반 예약에서도 버튼 요청·클릭 거절·사이트 기록 확인 등을 별도로 기록합니다. 별도 HTTPS 서버 진단은 제거했습니다.
- 로그 업로드를 설정 상단의 **진단 · 제작자용** 카드로 이동했습니다. 최근 7일·200건의 일반 동작과 임시 시험 중 마지막 성공 업로드 이후 새 기록·수정만 올립니다. 임시 테스트 메뉴를 숨겨도 제작자 업로드는 유지됩니다. 일반용 빌드는 진단·업로드 기능이 비활성화됩니다.
- 오늘 화면에는 출결 내용만 표시합니다. 달력의 지난 날짜를 눌러 출석·조퇴·결석을 직접 저장·수정·삭제할 수 있습니다. 직접 입력은 앱에만 반영되며 서버 출결은 변경하지 않습니다.
- 출석 예약 켜기·끄기, 입실·퇴실 시간별 설정, 퇴실 시간 안에서 미처리 상태로 강의실을 벗어날 때 알림, 퇴실 17:50:05 시작 등 기존 개선을 유지합니다.

## 설치 후 내일 입실 시험

1. **classroom-attendance-0.7.0-creator-debug.apk**를 기존 앱 위에 업데이트 설치하세요. 앱을 삭제할 필요가 없으며 같은 서명으로 설정·기록을 유지합니다. 연결 탭 아래에서 **출석 메이트 0.7.0 · 제작자용**을 확인할 수 있습니다.
2. **출석 예약 → 켜기**, **Chrome 입실·퇴실 자동 클릭 → 켜기**를 확인하세요. 접근성 연결과 위치·알림·알람 권한 등 기본 설정 완료 표시도 확인합니다. 업데이트 후 접근성이 계속 연결 대기라면 휴대폰 설정에서 서비스를 껐다 켜세요.
3. 9월 15일 설정한 입실 시간(기본 **08:30–09:30**) 안에 강의실의 **TACADEMY_5G**에 연결해 일반 예약으로 시험하세요. 임시 메뉴의 조회 시험은 실제 출결 버튼을 누르지 않습니다.
4. 잠금 화면에서 멈추면 알림을 눌러 잠금을 해제하세요. 일반 예약에 임시 Extend Unlock 선택이 자동 적용되지는 않습니다. 화면을 직접 켜거나 잠금을 해제했다면 결과와 함께 알려 주세요.
5. 실제 완료는 Chrome의 입실 시각과 앱 완료 알림으로 확인합니다. 이후 **설정 상단 → 진단 · 제작자용 → 로그 확인 · GitHub 업로드**에서 로그를 올려 주세요.

업데이트 시 일반 예약은 복구되고 이전 임시 테스트 예약은 취소됩니다. 오류 때문에 자동 시도가 중단되면 Chrome에서 기록을 직접 확인하세요. 버튼 요청 로그만으로 서버 출결 성공을 판정하지 않습니다. 새 진단은 업데이트 이후 동작부터 기록하며 9월 14일 과거 클릭을 복원하지는 않습니다.

## 검증

기능 코드의 Java 단위 68개, Python 분석 10개, Android 15 검사 165개가 통과했습니다. 버전 갱신 후 제작자용·일반용 빌드와 단위 검사·lint·서명을 다시 확인했습니다. 실제 출석 서버를 호출하거나 출결을 실행한 검사는 없으며, 휴대폰의 실제 인증·Wi-Fi·잠금 상태에서는 사용자 시험이 필요합니다.
