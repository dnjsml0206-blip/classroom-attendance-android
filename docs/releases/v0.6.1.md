# 출석 메이트 v0.6.1

퇴실 여유 시간을 10초에서 **5초**로 조정했습니다. 퇴실 설정이 17:50이면 일반 출석 예약과 임시 퇴실 테스트 모두 **17:50:05부터** 처리합니다. 기본 재시도 종료 시각은 **18:00**으로 유지합니다. 오늘 화면·예약 안내·임시 테스트 버튼에도 변경된 시각을 표시합니다.

## 오늘 퇴실 시험

1. **classroom-attendance-0.6.1-debug.apk**를 기존 앱 위에 설치하세요.
2. 출석 예약·Chrome 자동 클릭·접근성 연결·필수 권한과 등록 Wi-Fi 연결을 확인하세요.
3. 설정 → 임시 메뉴 → 잠금 상태 테스트에서 **Extend Unlock**을 선택하고 **오늘 17:50:05 퇴실 테스트 예약**을 누르세요. 업데이트하면 이전 임시 예약이 취소되므로 다시 예약해야 합니다.
4. 휴대폰의 날짜 및 시간을 자동으로 설정하고, 시험 전 화면을 끈 채 기다리세요. 시험 후 결과와 직접 조작 여부를 기록하고 **로그 올리기 · GitHub**로 업로드하세요.

5초 여유는 휴대폰 시각을 기준으로 합니다. 실제 Chrome 동작과 사이트에 기록되는 퇴실 시각은 현장 시험에서 확인합니다.

검증: 단위·에뮬레이터 검사 93개 통과, APK 빌드·lint 검사 성공. 기존 v0.6.0과 같은 인증서로 서명했습니다.
