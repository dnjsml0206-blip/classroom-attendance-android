# 출석 메이트 v0.9.2

제작자용 APK: **classroom-attendance-0.9.2-creator-debug.apk**

기존 앱을 삭제하지 말고 APK로 업데이트하세요. 같은 서명을 사용하며 versionCode 17입니다. 설치 후 앱을 한 번 열어 출석 예약·접근성 연결 상태를 확인하세요.

## 이번 변경

- Chrome 화면을 클릭 전에 놓쳤을 때 최대 70초까지 제한적으로 복구를 기다립니다. 클릭 전 일시적인 실패 때문에 해당 시간대 자동 처리가 계속 보류되지 않도록 했습니다. 기존 접속 횟수·재시도 간격과 클릭 후 중복 방지는 유지합니다.
- 실패 시 잠금·현재 창·접근성 갱신·주소·버튼 인식·클릭 요청/접수·사이트 메시지를 따로 기록합니다. 사이트 인증/접속 거부/요청 제한/연결 오류를 실제로 읽은 경우만 해당 근거로 표시합니다. 화면을 읽지 못하면 사이트 차단 여부는 미확정입니다.
- 별도 설정 없이 상세 진단이 기존 **설정 맨 아래 → 진단 · 제작자용 → 로그 확인 · GitHub 업로드**에 포함됩니다. 진단용 사이트 접속을 추가하지 않으며, 쿠키·페이지 원문·이름을 저장하지 않습니다.
- 오늘 그림의 **스탠드 부분**을 누르면 출석 예약이 켜지고 꺼집니다. 낮·밤 그림의 전구와 주변 조명도 함께 바뀝니다. 별도 전등 아이콘은 제거했습니다.
- 달력에서 **오늘과 지난 날짜의 출석·조퇴·결석 및 선택적인 입실·퇴실 시각**을 직접 기록·수정·삭제할 수 있습니다. 앱의 수기 기록이며 사이트 공식 출결과 자동 처리 상태는 변경하지 않습니다.

## 확인된 범위

Java 단위 106개, 분석기 19개, 최신 Chrome 재현 119개, 업로드 검사 43개 통과. 앞선 스탠드·달력·예약 검사도 완료했습니다. Android 15 / Chrome 124의 로컬 시험 응답을 사용했으며 실제 출결을 제출하지 않았습니다. 마지막 버전 번호 변경 후 APK를 다시 빌드하고 같은 서명을 확인했습니다.

PIN·지문 인증이 필요한 잠금을 자동으로 우회하지 않습니다. 실제 갤럭시와 강의실 서버의 처리 성공은 다음 현장 시험에서 확인해야 합니다. 화면의 오류 문구도 Chrome 접근성 정보에서 누락될 수 있으므로, 로그의 ‘미확정’을 사이트 정상이나 차단으로 단정하지 않습니다.
