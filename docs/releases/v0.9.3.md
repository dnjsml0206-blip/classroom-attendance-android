# 출석 메이트 v0.9.3

제작자용 APK: **classroom-attendance-0.9.3-creator-debug.apk**

기존 앱을 삭제하지 말고 APK로 업데이트하세요. 이전 릴리스와 같은 서명을 사용하며 versionCode 18입니다. 설치 후 앱을 한 번 열어 출석 예약과 접근성 연결 상태를 확인하세요.

## 이번 변경

- 예약 OFF 뒤에도 5초 실행에서 시작한 결과 확인 작업이 남아 ON을 막던 문제를 수정했습니다. 끄기를 누르면 대기와 현재 작업을 종료하고 다시 켤 수 있습니다.
- 이미 보낸 클릭의 기록과 접속 제한은 유지합니다. 예약을 다시 켰을 때 미확인 클릭이 남아 있으면 완료 기록만 먼저 조회해 중복 클릭을 막습니다.
- 이미 입실한 경우 Chrome에서 확인한 입실 시각을 버튼 아래 작은 회색 글씨로 표시합니다. 퇴실 시각도 같은 방식으로 표시하며 다음 날에는 전날 시각을 표시하지 않습니다.
- Wi-Fi 상태를 오늘 탭 제목 우상단 배지로 이동했습니다. 연결은 녹색의 ‘대기 중’, 미연결은 주황색의 ‘와이파이 미연결’로 구분하며 낮·밤 테마를 적용합니다.

## 확인된 범위

Java 단위 106개, 로그 분석 19개, 예약·수동 실행 24개, 실제 Android Chrome의 로컬 응답 재현 25개, 오늘 화면 30개 검사 통과. 이미 입실된 경우 추가 제출 없이 시간을 표시하고, 미확인 클릭이 남은 상태에서 OFF/ON을 해도 다시 제출하지 않는 것을 검증했습니다. 실제 출석 서버 요청은 사용하지 않았습니다.
