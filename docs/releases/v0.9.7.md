## 달라지는 동작

- 입실 시간대에 등록 Wi-Fi가 인터넷 사용 가능·기본 연결 상태가 되면 바로 입실 확인을 시작합니다. 미연결 검사 때문에 다음 실행이 60초 미뤄지던 문제를 수정했습니다.
- Wi-Fi 변경과 기본 인터넷 전환을 모두 감지합니다. Android의 상태 반영 시차는 최대 3회의 짧은 로컬 재확인으로 보완하며, 이 확인으로 사이트에 요청하지 않습니다.
- Wi-Fi 설정 도우미에서 연결을 마친 경우에도 바로 출결 확인으로 이어집니다.
- 날짜·입실/퇴실 구간 변경 시 이전 구간의 로컬 대기를 이어받지 않습니다. 완료·휴강일·예약 OFF 조건과 기존 재접속 한도는 유지합니다.
- 연결 준비 상태 변화, 콜백 수신 시각, 자동 처리 전달 시점을 제작자 진단 로그에 추가했습니다. 오늘 출결 내역에는 설정·연결 동작 로그를 표시하지 않습니다.

‘바로 시작’은 연결 준비 확인 직후 자동 출결 흐름을 시작한다는 뜻입니다. Wi-Fi 자체의 인터넷 확인·화면 깨우기·Chrome 로딩·서버 완료 확인에는 시간이 더 필요합니다.
