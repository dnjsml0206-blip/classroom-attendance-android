# v0.9.25 · 사용 방식별 설정 정리

- 출석 예약·출석 시간·수업일 카드를 설정 탭으로 이동했습니다.
- 설정 제목을 간결하게 바꾸고 우상단에 초기설정 버튼을 추가했습니다.
- 초기 설정에 출석 주소, 세 가지 사용 방법, 순서별 준비 안내를 모았습니다.
- 자동출석 준비 목록을 직접 Chrome 출석·직접 잠금해제·Extended Unlock 순으로 나누고 연한 구분선을 넣었습니다.
- Chrome 자동 클릭은 마지막에 배치하고, 직접 잠금해제 방식에서도 필요함을 안내합니다.
- 빠른 설정의 이동 경로 및 초기 설정의 뒤로가기 동작을 새 구조에 맞췄습니다.
