# 출석 메이트 v0.5.0 · GitHub 로그 업로드

잠금 테스트 기록에 **로그 올리기 · GitHub** 버튼을 추가했습니다. 최근 최대 11개 시험을 미리 확인하고 비공개 저장소에 JSON 파일로 올릴 수 있습니다.

- 최초 1회 GitHub의 해당 저장소 Contents 쓰기 권한 연결 필요. 앱에서 발급 방법 안내
- 연결 토큰은 기기 내부에서 암호화하며 APK·로그에 포함하지 않음
- 기록별 방식, 판정·메모, 예약/실행 환경과 관찰된 단계 포함. 이전 버전 기록 유지
- 전송 중단 후 같은 로그 재시도 시 저장 여부 확인. 기존 파일 덮어쓰기와 중복 커밋 방지
- 업로드 완료 링크 열기·복사 지원
- 업로드 후 대화에서 ‘로그 분석해줘’라고 요청하면 방식별 결과와 다음 시험 방법 분석

**classroom-attendance-0.5.0-debug.apk**를 기존 앱 위에 설치하세요.
설정 → 잠금 상태 테스트 → 테스트 기록 → 로그 올리기 · GitHub에서 시작합니다.

실제 출결 시도는 기본 OFF이며, 서버 연결 진단은 출결 인증/API 성공을 뜻하지 않습니다.

검증: 단위 46개, Android 업로드 14개, 기존 잠금 메뉴 12개, 분석 도구 6개 통과. 검증용 JSON의 실제 GitHub 저장·재조회 확인. 휴대폰의 개인 토큰 연결은 설치 후 진행하세요.
