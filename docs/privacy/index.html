출석 메이트 개인정보 처리방침

시행일: 2026년 10월 15일 · 패키지: net.tacademy.attendance

출석 메이트는 휴대폰 Chrome의 출결 페이지를 이용한 출결 처리와 기록 관리를 돕는 앱입니다. 이 방침은 Google Play 일반 사용자용 0.9.26 이후 버전의 데이터 처리와, 별도로 제공되는 제작자용 진단 기능을 설명합니다.

문의는 GitHub 로그인 후 작성할 수 있습니다. 공개 게시판이므로 이름, 출결 원문, 위치, 인증정보 등 개인정보를 게시하지 마세요. 이 앱은 교육기관의 공식 앱이나 출결 서버 운영 주체가 아닙니다.

2. 접근·처리하는 정보와 목적

  • 출결 정보: Chrome 출결 화면에서 읽은 날짜, 입실·퇴실 시각과 사용자가 수정한 출석·지각·조퇴·결석·휴가 상태를 기기에 저장하여 달력과 출결률을 표시합니다.
  • 위치 및 Wi-Fi: 허용한 정확한 위치, 등록한 강의실 좌표·반경, Wi-Fi 이름과 연결 상태를 강의실 도착·이탈 및 출결 네트워크 조건 판단에 사용합니다. 예약 감시에 필요한 경우 앱이 화면에 보이지 않을 때도 위치를 처리합니다. 이동 경로를 서버에 전송하는 기능은 없습니다.
  • 접근성 화면 정보: 사용자가 접근성을 허용하면 Chrome의 화면 요소·텍스트·버튼을 읽어 출결 완료를 확인합니다. 자동 처리 선택 시 입실·퇴실 및 확인 버튼을 조작합니다. 설정 안내·출결 후 잠금 기능에는 관련 시스템 화면의 요소와 잠금 상태도 사용합니다. 출결 화면에 표시된 이름 등은 화면 탐색 중 접근될 수 있으나, 이름이나 페이지 전체 본문을 출결 기록 또는 진단 로그로 저장하도록 설계하지 않았습니다.
  • 설정 및 동작 기록: 예약 시간·수업일·휴강일·권한 상태·화면 및 잠금 상태·동작 시각·오류 코드·앱 버전·출결 확인 결과를 설정 유지와 오류 분석에 사용합니다.

3. 저장 위치와 외부 전송

일반 사용자용 앱의 출결 기록, 설정, 진단 기록은 앱 전용 기기 저장공간에 저장합니다. 개발자 서버로 자동 업로드하지 않습니다. 광고 SDK나 별도의 이용자 행동 분석 SDK를 포함하지 않습니다.

출결 처리 시 Chrome이 skplanet.atosoft.net에 접속합니다. 사이트는 Chrome의 기존 로그인·인증 상태 및 네트워크 정보를 사용해 출결을 처리하며, 해당 사이트의 정보 처리는 사이트 운영자의 정책을 따릅니다. 앱이 Chrome의 비밀번호나 인증 쿠키를 추출하여 개발자에게 보내는 기능은 없습니다.

자동출석을 끄더라도 접근성을 켜 두면 사용자가 직접 연 Chrome 출결 화면의 완료 기록을 기기에 저장할 수 있습니다. 자동 기록도 원하지 않으면 Android 설정에서 출석 메이트 접근성을 끄세요.

4. 제작자용 진단 기능

Google Play 일반 사용자용 빌드에서는 제작자 진단·로그 업로드 화면을 비활성화합니다. 별도 제작자용 빌드는 사용자가 로그 업로드를 직접 실행하면 출결 동작 시각·결과, 기기·앱 환경과 설정 진단 정보를 GitHub 저장소에 전송할 수 있습니다. 자동 업로드는 하지 않습니다. 공개 저장소로 업로드된 기록은 다른 사람이 열람하거나 복사할 수 있습니다. 앱 삭제만으로 GitHub 기록이 삭제되지는 않으며, 게시된 기록의 삭제 문의는 위 문의처를 이용하세요. GitHub의 서비스 처리에는 GitHub 개인정보처리방침이 적용됩니다.

5. 보관 및 삭제

출결 기록과 설정은 사용자가 삭제하거나 Android 앱 저장공간을 지울 때까지 기기에 유지됩니다. 진단 이벤트는 최대 200개·약 120KB로 제한하며, 조회 시 최근 7일 기록을 사용합니다. 오래된 저장 항목은 새 로그 기록 시 정리됩니다. 앱 데이터는 Android 자동 백업 대상에서 제외합니다.

전체 기기 내 정보를 삭제하려면 휴대폰 설정 → 애플리케이션 → 출석 메이트 → 저장공간 → 데이터 삭제를 사용하거나 앱을 삭제하세요. 앱에서 삭제한 기록은 출결 사이트의 공식 기록을 변경하거나 삭제하지 않습니다. 사이트 기록의 정정·삭제는 교육기관 또는 해당 사이트 운영자에게 요청해야 합니다.

6. 선택권 및 보호 조치

자동출석은 선택 기능입니다. 위치·접근성·알림 권한은 Android 설정에서 철회할 수 있으며 관련 기능이 제한될 수 있습니다. 출석 예약을 끄면 예약 자동 처리를 중지합니다. 기기 잠금 인증을 우회하거나 PIN·지문을 수집하지 않습니다.

앱 전용 저장공간과 Android 권한 체계를 사용하며, 앱에서 사용하는 출결·GitHub 연결은 HTTPS 주소를 사용합니다. 기기 접근 권한을 가진 사람은 기기 상태에 따라 저장정보에 접근할 수 있으므로 화면 잠금 등 기기 보호 설정을 유지하세요.

7. 방침 변경

데이터 처리 방식이 변경되면 이 페이지의 시행일과 내용을 갱신하고, 필요한 경우 앱에서 변경사항 및 추가 동의를 안내합니다.
