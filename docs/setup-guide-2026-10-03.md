# v0.9.17 · 처음 자동출석 설정 가이드

설정과 연결 탭 맨 위에 5단계 가이드를 추가하고, 설정 미완료 사용자는 오늘 화면에서 시작·이어하기를 할 수 있게 했다. 기존 상세 설정은 그대로 사용할 수 있다. 반복되던 설정 탭의 긴 권한 목록은 단계별 안내로 연결한다.

1. **Chrome 연결**: 본인 이름과 출결 화면 확인, 등록 Wi-Fi와 일정 확인. Chrome 인증은 사용자 확인 체크로 구분한다. 현재 Wi-Fi 접속은 초기 설정 완료 조건이 아니다.
2. **버튼 자동 클릭**: Chrome 접근성 설정으로 이동한다. 설정 토글이 켜진 것과 서비스가 실제 연결된 것을 구분하며, 제한된 설정에 막힐 때의 경로를 도움말로 제공한다.
3. **예약 실행 권한**: 정확한 위치 → 항상 허용, 휴대폰 위치, 정확한 알람, 출결 알림을 측정한다. 알림 버튼은 앱 내부 설정을 연다. 배터리 제한 해제는 권장 항목이고 직접 확인과 시스템 측정을 구분한다.
4. **잠금 중 처리**: Extend Unlock 설정으로 이동, 신뢰 장소/기기 등록과 최초 PIN 해제를 안내한다. 보안 잠금은 측정하며 Extend Unlock 자체는 사용자 확인이다. 실제 활성화 여부나 향후 무조작 출결 성공을 확정하지 않는다. 최대 4시간, Wi-Fi와 신뢰 장소의 차이, 출결 후 잠금 모드의 PIN 요구를 안내한다. 제작자 테스트가 표시되는 버전에서만 기존 대체 클릭 연습으로 연결한다.
5. **최종 확인**: 미완료 단계로 바로 이동하며, 사용자 확인 후에만 예약과 자동 클릭을 켠다. 현재 조건이 맞으면 5초 뒤 실제 출결 시도가 가능함을 명시한다. 가이드 방문·단계 전환은 권한이나 예약 상태를 바꾸지 않는다.

가이드는 마지막 단계를 저장하고 설정 복귀 후 상태를 갱신한다. 강의실 위치와 배터리 설정은 부가 항목으로 취급한다. 예약 시작은 비공개 가이드의 Activity 결과로만 전달하며 exported MainActivity의 외부 extra로 활성화하지 않는다. 두 화면에서 필수 조건을 다시 확인한다.

v0.9.16의 지각·조퇴 매회 결석 ⅓일 반영 수정도 포함한다. 현재 로컬 업데이트이며 GitHub에는 아직 배포하지 않았다.
